# Reference 文件目录与权威定义索引

> 本文件是维护者使用的目录，不属于运行时 Skill 入口，不应在常规创作任务中加载。运行时路由以 `SKILL.md` 的“意图 → 必读路由”表为准。

## 文件导航

references 按**权责**分五组。在编文件开头都有「管辖范围」表头，写明**它权威负责什么**与**别处更全的指向**——冲突时以表头标注的「权威定义」为准。源技能废弃文档在 `docs/retired/`，调研存档在 `docs/research/`，均不加载。

**加载纪律（硬约束＝硬规则 20，全文见 `delivery-rules.md`）**：技能启动后**默认只通读本文件一份**；30 份 references 一律**按需索引、按需加载**——意图 Grill 画像确认之前不读任何 reference（要查口径时只开对应那一份），确认之后按「意图 → 必读路由」表逐份打开，路由没命中的不开。**一次性全量加载（并行读多份、顺序读全部、"熟悉技能"式读库）一律违规**。

**① 规则本体**：一句话口径 · 意图 Grill · 工作流在本文件；本文件的铁律与一般硬规则速查用于常规任务。下面两份仍是权威全文，但不再要求每次无条件通读：遇到规则冲突或边界判断、用户要求完整审计、专项规则无法由摘要确定，或校验失败需要追因时，再按需读取对应全文。常规任务必须遵守本文件摘要中的核心约束，不得因为未读全文而忽略已知规则。
