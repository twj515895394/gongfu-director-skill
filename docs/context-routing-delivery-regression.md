# 上下文路由与交付模式回归用例

> 用途：在修改 Skill 路由、上下文加载或交付策略后，按这些案例进行人工/模型回归。它们验证的是能力组合与质量约束，不是只验证文件是否被读取。

## 用例 1：简单双人对话

**输入**：两人站在办公室内对话，动作很少，用户未要求俯视图，使用常规视频模型。

- 预期加载：核心规则、`camera-language.md` 的相关镜头规则、`output-format.md`。
- 预期交付：中文分镜稿 + 完整生成提示词；标准模式下提供精简逐镜速览与关键校验结论。
- 默认不加载：`heavy-impact-playbook.md`、`action-vocabulary.md`、完整审计清单。
- 默认不生成 PNG；仍须逐镜核对朝向、机位侧、画面左右和视线方向。
- 质量门槛：不能因为省略 PNG 而出现轴线跳变或角色朝向不明。

## 用例 2：咏春短打 + 强重击感 + 克制特效

**输入**：两人近身咏春格斗，连续短拳，拳拳到肉、每次命中都有明显冲击，但不要夸张动漫特效。

- 预期加载：`unarmed-combat-classics.md` + `impact-intensity.md`；需要多样化化解时再加载 `action-vocabulary.md`。
- 不应仅因“打击感强”加载完整 `heavy-impact-playbook.md`，也不得将咏春替换成大开大合的摆拳/过顶下砸。
- 不自动添加：静帧、残影、集中线、黑白闪、夸张飞退或见血。
- 质量门槛：每次关键命中仍写清接触点、受力方向、身体反应与后续动作；镜头震动和音效与命中同步且克制。

## 用例 3：明确的大开大合重击流

**输入**：用户明确要求大开大合的重击流、完整挥击弧线、冲刺段与少量残影。

- 预期加载：`heavy-impact-playbook.md` 对应打法/速度/残影章节；如要求动漫冲击帧再加载 `impact-flash.md`。
- 不加载：水材质、赛车或其他不相关知识库。
- 质量门槛：重击专属配额按权威文件执行，冲刺位移有因果与空间锚点，不出现超额静帧/残影。

## 用例 4：咏春动作体系 + 极强单次反击

**输入**：保留咏春近身短打；对手压迫后，角色以一次短促反击打出极强冲击，但不改变整场动作风格。

- 预期加载：`unarmed-combat-classics.md` + `impact-intensity.md`；只有明确指定特定静帧/残影等专项表现时，才按需读取该专项规则。
- 不应因为单次反击很重就将全片动作路线切换成重击流。
- 质量门槛：动作体系保持一致；强度集中在指定反击，前后攻防节奏自然。

## 用例 5：H3 五镜打斗提示词

**输入**：用户明确指定 H3，要求五镜空手打斗，给出角色与场景参考图编号。

- 预期加载：空手路线、`output-format.md`、`storyboard-structure.md`；其他模块按表现需求加载。
- 预期交付：中文审阅稿 + 纯英文六段式 `.txt`，两者逐镜对齐；H3 正文满足首行/末行/零中文/字符限制。
- 不默认加载：`full-audit-checklist.md`，除非出现复杂空间风险、严格额外约束、校验失败或用户要求全量审计。
- 质量门槛：精简校验报告不影响完整提示词内容、动作链与用户点名的镜头。

## 用例 6：多人围攻 + 大幅位移 + 长镜头

**输入**：三人以上在狭窄场地连续攻防，角色有大幅位移，要求一镜到底。

- 预期加载：`long-take-directing.md`、`scene-playbooks.md` 对应章节、`continuity-ledger.md`；加载 `blocking-diagram.md` 并生成 PNG。
- 预期校验：长镜头专项密度、三维锚点、镜头连续性、角色朝向、攻击链和空间状态交接；复杂度高时启用完整审计。
- 质量门槛：不能因为默认精简交付而省略必要调度图或长镜头专项检查。

## 用例 7：用户要求完整审计

**输入**：用户明确要求逐项审计密度、伤情、动作分布、切点、连续性与版本差异。

- 预期加载：`full-audit-checklist.md` + `action-timing.md` 对应章节 + 当前任务实际涉及的专项规则。
- 预期交付：标准产物 + 适用的详细审计表与失败依据；不适用的专项不强行填表。
- 质量门槛：报告与正文逐镜一致；数值优先由脚本核算，脚本异常时复核脚本而非盲信结果。

## 用例 8：生成结果反馈诊断

**输入**：用户反馈生成视频中人物受击后没有后退、身体朝向跳变或动作链断裂。

- 预期加载：`generation-feedback.md` 中相似案例 + 对应的 `impact-intensity.md`、`action-physics.md` 或 `continuity-ledger.md`。
- 不默认重读所有历史案例或整套动作手册。
- 质量门槛：诊断要区分提示词缺失、模型能力限制与规则冲突；修复后只重跑受影响的检查组。

## 回归记录模板

每次实施后记录：

- [ ] 预期模块与实际读取模块一致；没有不相关模块的全量加载。
- [ ] 用户指定的动作体系、表现强度、特效约束与目标格式均被保留。
- [ ] 核心创作产物完整可用；必要的空间图示没有被误省略。
- [ ] 基础校验与当前任务专项校验通过；完整审计按触发条件执行。
- [ ] 质量评分与基线相比无硬失败；记录输入/输出 Token 或可复现的替代指标。
