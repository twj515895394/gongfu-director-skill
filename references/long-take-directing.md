## 一、定位与红线

长镜头流 = 运镜是主角，剪辑退场。 快剪流靠「切」制造节奏，长镜头流靠镜头自己的运动制造节奏。

| | 快剪流 | 长镜头流 |
|---|---|---|
| 时间单位 | 镜（1–1.5s） | 镜（5–15s，由用户点名） |
| 节奏来源 | 切点位置 | 运镜节拍（加速 / 反向 / 掠过 / 拉升） |
| 观众位置 | 旁观者，被剪辑带着看 | 参与者——被摄影机带着飞 |
| 密度 | ≥ 8 拍/秒 | ≥ 4 拍/秒（纯位移段另见六·7） |
| 距离 | 默认周旋 + 拉开（禁跑/禁追） | 放开，三维空间任意穿梭 |

红线三条（不改）

1. 不许变成游戏第三人称跟随（铁律 12）。这是长镜头流的头号死法——尤其立体机动这类「跟着人飞」的镜头。判据是这一镜有没有自己的电影机位逻辑（为什么是这个方位、这个高度、这个距离），答不上来就是游戏相机。过肩跟拍合法，焊死在后背当操作视角 = 禁。
2. 不许出漫画式效果线（铁律 13）。高速穿梭是速度线的高发区。学立体机动只学运镜，不学它的集中线——那部分必须整块剥掉，用运动模糊 + 元素拖尾 + 残影替代。
3. 不许慢动作（铁律 2）。长镜头天然想「慢慢地环绕展示」，那正是隐性慢动作。总纲写死 `it never sits still, and it never orbits slowly`。

## 三、三维空间运镜（立体机动穿梭 · 重力错位）· 最具价值的一套

立体机动段落有一套稳定的镜头序列——可直接搬进分镜的模板。

### 3.1 四段式运镜序列（一个完整的立体机动攻击段）

1. 冲出——摄影机落在角色侧后方，随他沿尾迹飞向画面深处的标靶；背景层每一帧都在移动。
2. 过肩悬停——距离拉近到过肩视点，尤其在角色滞留在高空的那一瞬间，让观众与他一起自上而下沿钩索瞄准目标。
3. 反打——从标靶（被攻击方）的角度反打，给攻击者的脸部特写；观众在这个镜像关系里对他的情绪感同身受。
4. 拉远收束——稍微拉远，用中景呈现斩击 / 命中造成的效果，而不是给命中的瞬间。

### 3.2 三条运镜心法

- 「观众在用一具虚拟身体使用这套装置」——镜头可以比角色更快地回旋去旁观他；也可以切进他的主观视点去体验飞行。主客观视点的切换本身就是一个运镜节拍。
- 距离是变量，不是常量——多人同时飞行时，镜头与各个飞行者之间的距离不断变化，形成「追踪游戏」：一会儿跟上甲，一会儿被乙甩开，一会儿绕到丙前面。每一镜要写出镜头此刻追的是谁、被谁甩开。
- 视点可以有意误导——颠簸的镜头让人以为是被甩开者的主观视点，下一拍他从画面侧方飞入。这是长镜头独有的叙事手段，可以偶尔用一次。

### 3.3 三维空间的物理可信度

- 钩索必须有落点——每一次转向写明锚在哪（建筑 / 树干 / 岩壁）；两根索交替制动形成三角受力。
- 不许凭空转向——变向要有受力来源（索的拉力、喷气的推力、蹬踏的反作用）。
- 不许滑翔式平移——那会立刻变成飞行模拟器画面（= 游戏视角）。
- 锚点清单必须落进分镜：这一镜借用的是场地里的哪几处（墙 / 杆 / 塔 / 树 / 断崖）。

### 3.4 重力错位：镜头沿光轴滚转 90°

机制：人贴在立面上时，身体轴与真实重力错开 90°（脚踩墙面 = 身体垂直于墙）。镜头跟着错开 90°，于是——

- 两人在画面里始终正常站立
- 立面读作「地面」，朝画面深处延伸
- 整座城市、天空、以及楼自己的竖直方向，全部横在画面里（楼的竖边 = 画面的横边）
- 真实重力在画面里指向一侧（用户要哪侧写哪侧，如「画面左 = 下」）

正统做法：不是「镜头自己滚转」，而是镜头与「地面」锁定、随它一起转——这是被验证过的做法（《皇家婚礼》1951 转钢笼摄影机随房间转、《2001》1968 相机固定在离心机、《盗梦空间》2010 的 Locked-off Camera Rotation 与 Free Camera Floating 两法并用），而且把「谁保持水平」说清楚了。

写法：`the camera is locked to the facade and rotates with it, so the facade itself stays level in frame while the city rotates around the two men` ——比 `the camera rolls 90 degrees` 更好执行。两种表述可并用：「镜头锁在立面上」（机制）+「镜头沿光轴滚转 90°」（用户能听懂的讲法）。

两个必写细节（不做这两件，翻转读不出来）

1. 旧重力的残留与延迟——翻转那一瞬，头发和衣料还带着上一个重力方向，要过几拍才跟上。
   例：`at 1.750s the hair and clothing still hang toward the old downward and only settle onto the new ground two beats later`。这是让观众「看懂换了个重力」的关键，漏写就等于没转。
2. 用痕迹交代「墙是他们的地面」——不靠任何特效，靠留在墙上的痕迹：脚印、擦痕、被踩碎的表面。收尾给一记墙面痕迹特写（玻璃幕墙的对应物就是碎玻璃的串——玻璃既然会碎，那串碎口本身就是「他们刚才走过的是墙」的交代）。

心法一句话：转的是世界，不是人。 镜头滚转的角度必须与两人转体的角度相等，两人在画面里才保持竖直；差一点就会变成「人歪着」。

白送的两个画面细节（记忆点）

1. 真实下坠在画面里是横向飞出去——谁脱手，谁横着飞出画面；
2. 被震落的碎玻璃在画面里也横着飞，方向与重力一致。

必须挂参照物（否则观众读不出高度）：世界横过来后观众会短暂失去判断——一直给三样：① 天际线 / 远处楼群 / 云 压在画面某一侧 ② 幕墙自己的网格（竖框横梁）一格一格掠过，读的就是下滑距离 ③ 偶尔让整栋楼入画，那是唯一能把「几千米高」讲清楚的镜头。

滚转是一个运镜节拍，不是硬切——翻转必须用连续时间走完（实测 1.250s 走完 90°），中途不许跳变；翻转过程中必须同时写明两人的姿态在变（收腿、以靴底去贴立面），否则会出现「镜头转了但人没转」的穿帮。

与铁律 12 的关系：贴立面滑行 + 跟随镜头，天然就是第三人称跟随游戏的形态（头号禁项）。解法：镜头贴着立面表面横移，靠幕墙竖框 / 横梁 / 破碎点当参照物读出移动距离，不吊在两人身后——这样它才是电影机位，不是操作视角。

### 3.5 垂直面移动（`Wall Run` / `Wall Crawl`）· 有正式名字的成熟套路

这不是新点子——TV Tropes 有专门条目（`Wall Run` 跑上去 / `Wall Crawl` 附着攀爬），例子横跨漫画 / 动画 / 电影 / 游戏。所以动手前先搜套路名，不要当原创从零设计（漏搜这步会被用户反问「全网没有这种打戏吗」）。

三种处理法，先选一种

| 处理法 | 怎么交代 | 例 |
|---|---|---|
| ① 装备 / 法术显式交代 | 吸附法术、磁力靴、粘性手套，会有可见特效 | 《魔法少女奈叶 StrikerS》的 Absorb Grip · 各类磁吸装置 |
| ② 设定显式交代 | 一句设定讲清能量从哪来 | 《火影忍者》查克拉聚于脚底 · 《我的英雄学院》Spinner 的「Gecko」个性 |
| ③ 完全不解释、也不表现（用户要的） | 只靠动作本身 + 留下的痕迹，一个字都不解释 | 《K》Missing Kings：两人在摩天楼外墙上剑斗，一方先像是要掉下去，随后也站住了 |

> ②里「踩得太猛会把墙面踩裂」值得记住——它证明「垂直面移动 → 把表面踩碎」是同类作品的既有语汇，「玻璃被踏碎」不是硬编的。

③ 的正统交代手法 = 痕迹，不是特效：留在墙上的脚印 / 擦痕 / 被踩碎的表面，经典收尾是一记墙面痕迹特写。这与铁律 7「能力不解释、不视觉化」同源——能力归铁律 7 管，不在这里加特效。

## 四、单镜穿场与连续跟随

单镜穿场 = 一个镜头里角色穿过多个空间，中间不切。

- 写法：摄影机贴着角色穿门、过廊、上楼、破窗，空间一个接一个展开；每一次「穿过」都是天然的段落分隔，不需要切。
- 关键：穿过的一瞬间要有物理接触（推门、掀帘、破玻璃、撞开人群）——那是镜头的「标点」，否则穿场会糊成一段连续平移。
- 《爱情公寓 3》式的 CG 打斗：角色 CG 化后连续跟随 + 穿场，镜头始终在人的运动轴线上。可取的是运动轴线不断，不是它的具体招式。
- 换主体不换镜（*Birdman* 的做法）：镜头从甲背后转到甲正面，或把跟的主体从甲换成乙——这在感知上相当于长镜头内部的「标点」，制造镜内节奏，是长镜头里唯一合法的"切"。

## 五、运镜节拍（长镜头的节奏单位）

快剪流的单位是「拍」，长镜头流的单位是「运镜节拍」。
一拍 = 0.125s（不变）；一节拍 = 一次运镜状态改变，必须落时间码。

七种节拍（每一镜至少用到两种，全片不许只有一种）

1. 加速——镜头突然跟上 / 甩开（对应冲刺、爆发）
2. 反向——镜头运动方向掉头（对应攻守转换、绕过结构件变向）
3. 掠过——贴地、贴墙或贴面高速掠过（对应位移）
4. 拉升 / 俯冲——高度突变（对应腾空、落地、俯视局势）
5. 绕转——镜头绕着斗者转（不许写成 slow orbit，必须是快速绕转或受击带动的转）
6. 换主体——跟的主体从甲换成乙（镜内的"切"）
7. 滚转——镜头沿光轴转（`roll`），不改变方位只改变画面朝向；重力错位靠它（见 3.4）。与 5 的区别：绕转是机位移动，滚转是机身自转——写的时候必须分清，别混成一个词。

密度口径：长镜头流 ≥ 4 拍/秒（不是 8）。一拍仍是 0.125s，但长镜头里一拍可以容纳更长的连续动作（一次挥满可以占 2–3 拍而不切走）。不许把 8 拍/秒硬塞进长镜头——塞进去会变成手腕乱抖。

运镜节拍清单（交付时逐镜报出）：镜号 → 节拍序列（带时间码）→ 镜头此刻追谁 → 被谁甩开。

### 5.1 速度感镜头语汇

节拍对了，不等于观众感觉到快。 只写运镜节拍、没写速度语汇，用户一眼看出来「没有速度感」——这是长镜头流最容易漏的一件，别再漏。

快剪流的速度靠「切」；长镜头流没有切，速度只能靠镜头在镜内做极端的位置变化。 四件语汇：

1. 低角度足部 / 接触点特写仰拍（最有效的一记）——镜头猛压到贴地、仰拍，拍脚掌踏下去、表面炸开、碎屑横飞。只停半拍就抬起来，别变成静止展示。
2. 前景飞速掠过物——碎片、横梁、枝叶从镜头前一寸处横穿而过，把画面挡住一瞬。前景遮挡是最强的速度语汇，因为它给了观众一把「参照物在飞」的尺子。
3. 贴身跟随——镜头贴进主体的运动轴跟着一起冲，不是保持距离在旁边拍。
4. 景别突变——从全景猛贴到局部、或反过来。退与贴都是机位移动，不是变焦推拉（禁 zoom）。

配额与例外

- 铁律 6 的景别配额在长镜头流下已豁免，足部特写不占配额。
- 一次长镜里给一到两记足矣——给多了会变成碎片化的展示，反而把连续的冲劲打断。

> 速度感与慢动作是两件事：速度感靠上面四件 + motion blur + 元素拖尾；慢动作是「极少」的稀有资源，只在铁律 2 三个关节节点用。不交手的段慢动作整条不用。

## 六、长镜头专属校验（用户点名长镜头流时，在 21 项之外加跑）

词表与数法都给全，脚本照抄。

1. 镜数——镜数 = 用户点名数；不许再套「镜数 ≥ 片长秒数」。逐镜时长 ≤ 15s（H3 单次上限）。
2. 无断裂——全片切点数 = 镜数 − 1（长镜头流通常 = 0）。禁词 0 命中：`切` / `硬切` / `cut to` / `CUT TO` / `dissolve` / `fade` / `wipe` / `morph` / `cross-fade`。（例外：约束块里声明「本段不切」的否定句，属否定语境放行。）
3. 运镜节拍——逐镜列出节拍序列，每条落时间码；全片节拍种类 ≥ 3；同一镜内不许从头到尾只有一种节拍。
4. 三维锚点——列出每镜借用的场地锚点；镜头飞出去后必须飞回那片场地；不许无参照物的空旷滑行（= 飞行模拟器感）。
5. 机位逻辑——逐镜答一句「这一镜自己的电影机位逻辑是什么」（方位 + 高度 + 为什么是这里）。答不上来的镜一律重选。禁词 0 命中：
   中文 `第三人称` · `背后跟随` · `背后视角` · `锁定轴` · `玩家视角` · `战术视角` · `俯视战场` · `斜45°` · `等距` · `横版` · `侧视`；
   英文 `third-person follow` · `behind-the-shoulder follow` · `locked to the back` · `player camera` · `gameplay camera` · `top-down tactical` · `isometric` · `side-scrolling` · `versus screen`。
   （`top-down` 单独出现不判违规——俯视上帝视角是合法的电影机位；要连 `tactical` / `gameplay` 一起看。）
6. 禁漫画线（加严）——高速穿梭段必扫，0 命中：
   中文 `集中线` · `速度线` · `效果线` · `辐射线` · `动作线` · `冲击线` · `擦布线` · `漫画线`；
   英文 `radial speed lines` · `speed lines` · `action lines` · `impact lines` · `motion lines` · `converging lines`。
7. 密度——先判这一段有没有交手，别把攻防密度套到没有攻防的段上：
   - 有交手的段：≥ 4 拍/秒，按整秒滑动窗口跑（长镜头的总平均特别容易骗人）。
   - 纯位移段（全程不交手，如纯滑行 / 纯追逐 / 纯坠落）：「回合」不存在 → 攻防密度整条不适用。改核三项——
     ① 动作锚点 ≥ 2 拍/秒，且任意两个相邻锚点间隔 ≤ 1.000s（防长洞）；
     ② 运镜节拍 ≥ 5 类（纯位移段只有镜头在制造节奏，节拍种类就是密度）；
     ③ 全程无一处静止（没有任何「停住 / 稳住 / 落定」类完成态）。
     → 实测口径：纯位移段按动作锚点判，间隔序列要数、别只看总个数——相邻锚点间的大洞（如滚转全程无锚点）必须补中间状态；「每 0.375s 碎一块」这类写法要逐个落时间码。
8. 慢动作——`slowly` / `slow orbit` / `缓慢环绕` 0 命中；合法慢动作仍是铁律 2 的三个关节节点，落在帧上不落整镜。

## 七、与快剪流互转（同一段内容改道时换什么）

用户在同一段创意上说「换成快剪」或「我要一镜到底」时，不是加减镜头，是换语言。

| 元素 | 快剪流 | 长镜头流 |
|---|---|---|
| 切点 | 是节奏本体 | 不存在，改为运镜节拍 |
| 「切本身是一次动作」 | 成立 | 失效——改为「镜头转身就是一次动作」 |
| 招式细节 | 每镜只留一个触点 | 必须连续可见：一次挥满要完整走完三段 |
| 伤情 | 可以不累积（切掩盖） | 累积不重置——每一记都留着（*Atomic Blonde* 的做法） |
| 距离 | 默认周旋（距离放开） | 是变量，逐镜写明追谁 / 被谁甩开 |
| 景别 | 逐镜不同 | 镜内连续变化；一个镜头可以从全景推成人脸 |

改道时必查：原来靠「切在动作中间」制造的紧迫感，在长镜头里必须换成运镜的不稳定性（被甩开又追上 / 镜头受击上抬 / 贴地掠行）——否则整段会变平。

## 八、五个坑

1. 滑成游戏第三人称跟随——头号死法。每次写「镜头跟着谁」都要同时写出为什么这个机位。
2. 速度线冒出来——尤其学《巨人》时。只学运镜，剥掉线（铁律 13）。
3. 慢慢环绕——长镜头天然想「展示」，`slowly arcing` 是隐性慢动作（铁律 2）。
4. 空旷滑行——镜头飞出去不回来、没有锚点，画面失去空间参照，立刻像游戏过场动画。
5. 与 H3 分段打架（技术硬约束，必须提前跟用户讲清）：H3 单次生成上限 15s。若长镜头设计超过 15s，只有两条路——
   ① 压到 15s 内（推荐，长镜头本来就该短于用户以为的长度）；
   ② 拆两段接力：第二段 `detailed_description` 开头写接缝句，逐字复述第一段末镜的姿态与镜头位置，并在结构约束里声明「本段是第一段同一镜头的延续，不许重新建立景别」。
   长镜头拆段比快剪拆段难——快剪接缝天然不显，长镜头接缝一露就穿帮。每段独立喂参考图（模型无跨段记忆）。
