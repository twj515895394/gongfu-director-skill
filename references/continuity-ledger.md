# 逐镜状态与切点交接

<!-- scope-header -->
> **管辖范围**（本文权威负责什么 · 别处更全的指向）
>
> - **本文负责**：逐镜连续性台账：三套方向体系（世界 / 画面 / 银幕）· 逐镜初末态记录 · 运动轨迹四问审计 · 交接与接物句式。
> - **不在本文找**：轴线与银幕方向的规则本体（→ `camera-language.md`）· 动能闭环规则本体（→ `iron-rules.md` 铁律 1）· 交付形态（→ `output-format.md`；台账是内部审计工具，不默认交付）。
> - **权威定义**：逐镜初末态与轨迹审计**怎么记、怎么数**以本文为准；方向与越轴的**判定**以 `camera-language.md` 为准。

多镜、复杂交互或连续性修复时必读。先建立一条世界事件线，再让摄影机从不同位置观看它；不能每换一镜重新生成一个场景。此处台账是内部写作工具，不是新增 H3 字段，也不默认作为附件交付。

## 1. 建立稳定的场景关系

选最少但足够的固定地标，如门、断墙、桥端、桌沿。记录人物起点、身体朝向、视线目标、相互距离/高低、可通行路线、重要道具与主光位置。简单对话无需精确三维坐标；复杂交锋可以用平面草图或相对方位辅助，最终只保留影响观看的事实。

严格区分三套方向：

- **世界方向：** 朝北门、离开断墙、向桥东端移动，不随相机换位改变。
- **角色自身方向：** 角色的右手、左腿、自身右侧，由角色朝向决定。例如面向东时，自身右侧朝南，不能直接称画右。
- **画面方向：** 当前机位看到的左/右、前景/后景、出入画边缘，是投影结果；换机位须重新推导。

每个互动段指定有效轴及相机在哪一侧。多人戏以当前主要交互确定轴，必要时先用关系镜交代第三人的位置；人物移动、新目标加入或转弯时，检查旧轴是否仍适用。默认保持可读的同侧拍摄；可见走位建立新轴时，要在镜内让观众看见变化。中性正轴、特写、黑场、甩镜或烟雾不自动允许镜后换边。

把地标也纳入投影核对：固定机位、固定取景下，门、柱、墙等静物的画面位置与相互左右关系不能改变。人物走向固定门口并经过前景柱时，路线必须实际穿过柱的视线遮挡区；结合起点、重现侧和终点检查一次。不能开场把门放在柱的画右，随后在同一固定视点让人物从柱左出现、沿不再越柱的直路却到达该门。相机移动时可产生视差，须由具体路径解释，不能用摇摄或“同侧”一句话豁免几何检查。

## 2. 逐镜记录初态和末态

用下面的精简结构记录相关项；不存在的属性不填，关键项未知时先解决，不能用“保持一致”代替具体内容。

| 项 | 记录什么 |
|---|---|
| 时间 | 所属事件线；故事时间与屏幕时间；与前镜连续/省略/同时交叉/回忆或联想；正常速或指定慢放 |
| 相机 | 位置、高度、观看方向、有效轴及同侧依据；运镜起止路线；画内左右和前后景 |
| 人物 | 相对地标的位置与距离、身体朝向、视线目标、是否在画内；初态 → 末态 |
| 动作 | 唯一的一次事件、当前阶段；世界水平与垂直运动分别记录方向、速度趋势、轨迹阶段和目的地；身体姿态/旋转另记；起手/运动中/接触/分离/落定 |
| 运动改变 | 重力、碰撞、支撑、主动转向或设定中的外力；何时开始、改变哪些分量；没有改变的分量继续继承，不编造精确数值 |
| 接触和支撑 | 哪只手持何物，另一只手是否空闲；谁接触谁的哪个部位；承重脚、悬空/跪/站姿；接触发生或解除的时刻 |
| 攻击事件 | 按 scene-playbooks.md 的接触点审计逐次记录；原目标与实际接触分开，接触双方的侧别/部位或兵器段位/表面、共同区域及阶段明确；跨镜继承同一事件，滑动/分离后再接触须有过程 |
| 持续状态 | 道具位置/所有者、衣发惯性、衣损/伤情/湿度、碎片落点、世界主光及声源 |
| 特效状态 | 仅填相关项：介质/能力、供给开关、源点/命中区、传播前沿与世界风向、主碎片/流体位置和速度趋势、烟尘浓淡/冷却阶段、持续光照与破损/湿痕；按 `vfx-quality.md` 物理存在判据定义 |
| 观看证据 | 末态实际能看见或听见什么；下镜第一句如何接住它；本镜的新变化 |

从前镜末态生成下镜初态，完成正文后再倒查一次。局部修订可能改变后续落点或持物，必须把差异沿后续事件线传递，直到状态重新吻合；不只修改单独一句。

## 3. 每个切点按时间关系验收

### 连续动作

内部写成：`前镜末态 → 下镜初态 → 下镜新增变化`。

切前后是同一事件的相邻时刻，位置、姿态、接触和速度应能连续到达；新角度的画面坐标可以改变，世界状态不因切镜改变。在可辨识相位切出，下镜接住该运动的下一瞬间，不能再从起手开始、再打中一次或在尚未接触时直接跳到战果。提示词不默认设计时间回放或动作重叠；若用户明确需要重播，标明时间关系。

每个连续切镜的开头用一句具体可见的承接锚，包含**实际需要延续的状态 + 决定本次连续性的关系信息**。动作镜写相位/接触与关键空间/持物；静态反打、反应镜或 POV 可以写姿态、目线目标、情绪或声画承接，不为了满足字段增加肢体动作。依据实际风险补另一方状态、地标或衣发惯性；不必每镜列全套数据。`continues seamlessly`、`same position`、`consistent spatial logic` 本身不算证据。

### 明确省略

允许初末态不同，但注明省略的时段/过程和可见的结果。区分无需展开的过路过程与必须看懂的关键因果；交接、命中、转向或落地若决定剧情，须可见，或按用户叙事意图给明确画外证据。不要为修补错误擅自加“几秒后”。

### 同时交叉

分别维护各条事件线及共同时间参照。切开期间本线继续推进，切回时依据实际经过的故事时间推导，而非冻结在离开那一帧；另一条线也不能凭空超前。慢放占用的屏幕时长不等于另一线同样长的故事时间，要注明同步区间。原地等待可以继续等待，但不是默认把所有物理过程暂停。

### 平行、回忆、联想与观念蒙太奇

给出各自的时空身份及具体连接依据，不要求无关场景的世界位置相等；相似构图或动作匹配不等于同一事件。明确回到主线的时间和状态，不能把用户有意的时间变更误判为连续性错误。

## 4. 运动轨迹审计：先推演，再切镜

所有跨镜运动都做这项检查，尤其是飞行、击飞、跳跃、坠落、追逐、抛射和翻滚。只记录影响连续性的关系，简单运动不必强加坐标、公式或固定时长。复杂空间可选世界轴或固定地标，并明确高度相对地面、平台或其他主体。

### 切点三时刻与因果

对每个运动切点，推演 **切前最后一小段 → 切后第一小段 → 后镜接下来发生的变化**，不能只比较两个静止姿势。内部至少明确：

1. **从哪里到哪里：** 前镜末位置、水平运动方向/速度趋势、垂直运动阶段、身体朝向/旋转、支撑或接触；后镜初态先继承这些事实，再按实际故事时间推进。切点允许正常运动进展，不要求相邻帧位置完全相等。
2. **什么改变了运动：** 指出变化的原因、开始时刻与作用对象。重力可持续改变垂直速度；落地、撞墙、牵拉、主动转向或魔法等按本故事规则改变相应运动。若没有原因，不能突然反向、停住、换高度或改成另一条轨迹；不要为通过检查擅自添加碰撞、瞬移或时间省略。
3. **相机看到什么：** 用同一世界轨迹推导新机位的画面位移，检查出入画侧、地标顺序、视线遮挡与终点。跟拍可能使人物留在画面中央，俯拍可能使某个分量不明显；这不代表人物停住或垂直坠落。若换视点使画面方向变化，给可见的地标/路径关系解释，保持有效轴可读。
4. **是否到得了：** 按事件时长与速度趋势检查后镜起点、接触对象和落点是否可达；慢放只改变屏幕呈现，不能另造一条物理轨迹。镜内分阶段运动也须顺序成立。

把身体运动与平移分开：脸朝下、身体竖直、空中翻滚都不自动意味着向下运动；“跌落”“滑行”“飞向”等概括词不能覆盖前镜确定的轨迹。追踪移动目标时，分别推进双方位置，检查相对距离、高度和接触时机，不能只跟踪主角。

### 飞行、跳跃与下坠

- 区分有持续推进的飞行、受击后的惯性运动、弹道跳跃、已有向下速度的坠落。依据用户世界规则处理，不把所有悬空动作套成自由落体，也不凭风格词忽略惯性。
- 向桥东端横向飞行后，若开始受重力下落，通常仍向东推进，轨迹逐渐下弯；“开始下落”并不等于“原地竖直下坠”。只有既定碰撞、牵制、主动减速等能解释水平运动改变时，才写相应变化。
- 向上抛起或跳跃可经过上升减速、最高点、下降；若切点正好位于最高点，下一镜下降可以成立。核对是否确实到达该阶段，以及仍有的水平运动，不能机械判定所有上升转下降都错误。
- 若后镜要直接呈现落地结果，检查时间关系和必要因果证据；不能把尚在水平飞行的前镜末态直接接成已经落地、原地下坠或重新起跳。

### 回归示例：向右飞行后切成下坠

设定：人物受击后向桥东端飞出，相机在桥南侧朝北，画面表现为向右移动；没有碰撞、牵拉或主动制动。

错误：`S1 末：人物仍快速向画右横飞 → S2 初：人物在原处笔直下坠。` 水平运动被无故清零，后镜也没有继承位置与轨迹。

可成立的交接：`S1 末：人物越过桥中央裂口，仍向东飞行，高度开始降低 → S2 初：人物已在裂口东侧，继续向东，沿同一轨迹向下弯曲 → S2 变化：逐渐接近东端下方的斜坡。` 后镜换成高位斜拍时仍描述相对裂口、东端和斜坡的运动，不只写“向下坠落”。

若用户指定后镜必须竖直下坠，则先判断既有剧情是否提供停止水平运动的原因；在允许重新设计时设计并呈现转折，在保留骨架任务中指出具体冲突，不能偷偷补一次撞击。若用户只是说“往右”且机位未定，先选择并锁定可解释的世界路线；不得在后镜重新解释成另一个方向。

## 5. 特别容易漏掉的交接

- **道具转移：** A 持有 → B 接触但 A 仍持有 → B 握稳 → A 释放 → B 携带；一个道具只有一条实际路径。关键共同握持要被描述，不能特写一切就已经换主人。换手要有过程；持剑手不能同时撑地。
- **格挡/击中：** 接近 → 接触或明确落空 → 力/速度改变 → 分离/位移 → 新支撑。按 scene-playbooks.md 逐次核实际接触双方与共同区域；原本瞄准胸口但被前臂挡住时，后镜继承拳对前臂，不能直接换成拳对胸口。武器锁住或滑动分别继承接触段位与变化路径。对手受击、武器偏折和伤情由这一次事件产生。特效与模糊不能遮掉唯一的接触证据。
- **转弯/换位：** 相对固定地标交代抵达、转向及新朝向，再按新轴设计镜头。不能为了让人物始终画右移动而改写世界路线；出画和入画方向都从机位与路线推导，不机械要求总从反边入画。
- **遮挡/画外：** 遮挡只隐藏可见性，世界时间和轨迹继续。重现位置、动作进度、持物、衣发必须能从消失前的状态到达；烟、立柱、前景擦镜不承担隐形传送。若接触有意在画外，给足声画因果，不自动增加画外攻击或交接。
- **双人分离：** 一方被推开时分别保存双方的位置、朝向、支撑/高度；另一方不默认跟着飞走或坠落。保持受伤部位对后续动作的限制。
- **物理余波：** 上镜刚急停，下镜的发尾、衣摆、液滴和尘土仍处于相应阶段，不能全部静止或从头重摆。反打保持同一世界光源，重新推算哪侧脸被照亮。
- **特效跨镜：** 上镜停止发射不代表已发出的弹体、尾流和碎片一起消失；连续束与飞行脉冲按各自机制继承。反打不移动源点/命中处，也不重新蓄力或再爆一次；推算风推烟尘、波前扩展和残骸落地的实际进度。前镜形成的缺口、断面、积水/湿痕和烧灼继续存在，明确复原能力或时间省略除外。光源位置/强度变化同步影响附近材质和脸部受光，不能只保留彩色亮斑。

## 6. 最小示例：接物切点

场景设定：A 在桌西侧朝东，B 在东侧朝西；主光来自西窗。相机位于桌南侧朝北，A 画左、B 画右。A 的右手持钥匙柄，B 的左手准备接住钥匙环。

错误：A 刚伸出钥匙 → 切 B 已独自握钥匙的近景。缺了触碰、握稳、释放，也没有证据说明时间省略。

正确的内部交接：

`S1 末：B 左手指触到钥匙环，A 右手仍夹住柄，钥匙在桌中央上方 → S2 初：同一触点与高度，双方仍共同接触 → S2 变化：B 左指闭合握稳后，A 右指才松开，B 左手收回。`

编译进下镜的正文可以是：

`From the same south side of the table, the close-up begins with B's left fingertips touching the key ring while A's right fingers still hold the key's stem above the table centre. B closes the left fingers securely around the ring; only then does A release, and B draws that same hand back toward the east end.`

不把方位词全套复制到所有例子；选择能让该动作明确的最少信息。该例只展示交接自然语言，镜号、时间码和声音仍按当前 H3 模式写。

## 7. 交付前沿时间线模拟一遍

按镜号读事件而非读漂亮构图：每镜开始的人/物从哪里来，手里是什么，上一阶段到哪里，下一变化如何发生，相机能否看见证据。连续关系中发现未解释的差异，先改走位、机位、切点或时长；不要靠追加“不要瞬移/不要越轴”的空泛负面句结案。

检查工具可以核时间加总或实际建立的几何关系，但词语匹配、坐标写满和每镜声明“同侧”都不证明连续性。最终依据是具体空间与动作描述能否同时成立。
