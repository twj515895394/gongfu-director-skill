## 二、固定项：出稿时一个都不许少

| 位置 | 固定项 |
|---|---|
| 全文 | 六段齐全且有序；首行 `subject_definitions:`、末行 `N/A`；除此之外不写任何说明 / 映射行 / 注记 |
| `subject_definitions` | 每个 item 独占一行；有参考图时零外貌描述，只写「由 <Picture N> 定义」+ 四视图取用规则 |
| `summary` | 方括号任务类型前缀（参考图只定义角色与场景 = `[reference generation]`）+ 概述 + 参考图角色 |
| `retention_analysis` | 每行恰好一个关系标记（`fully_preserved` 等），标记之后才是中文说明 |
| `detailed_description` | 风格段落放在 `[Shot 1]` 之前；持续元素一次声明 + release clause；结构约束块；逐镜正文；音效不写在这里 |
| 结构约束块 | 镜数与时长链 · 硬切禁令（dissolve / fade / cross-fade / wipe / morph / 黑场）· 防融合 · 轴线与左右关系 · 状态等式句 · 图像优先 · 禁漫画效果线 |
| 每镜 | 机位关系 · 谁前景谁后景 · 谁在画面左 / 右 · 景别 · 焦点落在谁 · 运镜方向与速度 · 人物姿态 · 脸部调用点名哪张图 · 末句切在行进中 |

| `overall_soundscape` | 按镜号排布；环境层 + 人物动作音；硬切处声场不断层 |
| `non_diegetic_music` | 用户要无音乐时必须显式写 `N/A`，不能留空 |

下面这 4 类看着像重复，其实是防漂移，不许删：

1. 轴线与「A 左 B 右」——summary + 约束块 + 每镜构图，三处。这是全片最容易翻车的地方。
2. 硬切禁令 + `CUT TO:` 字面——H3 默认往融合跑。
3. 「不是慢动作」每镜一次——只能缩短，不能只留一次。
4. 脸部锁定规则（定义句）+ 逐镜调用点——前者锁规则，后者说这镜用哪张图，是不同信息。

## 四、从这份范本读得出的写法标准

- 站位 · 画面位置 · 前景后景 · 运镜，逐镜写全——这四项是用户自己强调的重点。
- 时间码精确到毫秒，从不写「约」（硬规则 6）。
- 脸部镜头必须点名调用哪张图的哪一格，不能只写「面部特写」。
- 镜头慢 ≠ 慢动作：写了「缓慢平移」就要补「时间流速正常，不是升格」。
- 中文正文就是审阅件：一般人读得懂（硬规则 12），字段名不印出来。
- 短片也落不到整数秒：`duration: 4` 实际 4.458 秒，两镜按真实网格均分（2.229），别按 2.000 写。
