## 零、镜头逻辑：轴线与连续性（整份文件的地基）

这一节是地基——镜头语言学得再花，逻辑错了观众第一眼就出戏。以下是电影剪辑的连续性系统（continuity system），一百多年商业电影的默认语法。

### 1 · 180° 轴线原则（最重要的一条）

两个人物之间有一条假想的连线，叫「轴线」（180° 线）。摄像机必须始终待在轴线的同一侧。

- 轴线由什么构成：由两人的视线走向构成（A 看 B 的那条线）。即使两人没有互相对看，轴线依然存在。
- 为什么必须守：只要不越轴，站在画面左边的人就永远在左边，右边的永远在右边——观众的空间感不会错乱。越轴 = A 这一镜从画面左看着右边，下一镜变成从右边看着左边 = 观众懵。
- 在轴线一侧的九个标准机位（双人场景）：

| 机位 | 名称 | 长什么样 | 什么时候用 |
|---|---|---|---|
| ① | 关系镜头（主机位） | 全景，两人同框，建立空间关系 | 每场戏开头必给，它定下后续所有机位的依据 |
| ②③ | 平行镜头 | 单人侧面，视轴与 ① 同步 | 中景 / 中近景，人物侧脸 |
| ④⑤ | 外反拍（过肩） | 前景一人虚化，后景一人为实 | 最常用，强化两人位置与交流关系 |
| ⑥⑦ | 内反拍（正打反打） | 单人画面，各居画面一侧 | 叙事重点、突出人物 |
| ⑧⑨ | 骑轴镜头 | 视轴与轴线平行，人物直视镜头 | 主观视点，交流感最强；一般跟在 ①④⑤ 之后 |

- ②③ / ④⑤ / ⑥⑦ 都是成对用的——形成「反应与被反应」的呼应。
- 两条不可破：开场给 ① 关系镜头（建立空间）· 同侧，不出轴线。

### 2 · 30° 规则（防跳切）

切换到同一主体的镜头时，机位角度至少变化 30°（或明显改变焦距）。

- 角度变化不够 → 跳切（jump cut）：看起来像人物在原地抽搐一下，观众立刻出戏。
- 对策：换角度 ≥ 30° · 或换景别（中景 → 特写）· 或中间插一个别的镜头。

### 3 · 视线匹配（Eyeline Match）

A 看向画外的某个方向 → 下一镜显示他看的东西，且方位对得上。

- A 在镜 1 看向画右 → 镜 2 里的目标应出现在画面左侧（相机从 A 的位置反打过去）。
- 对不上 = 观众觉得两人看的不是同一个东西。

### 4 · 银幕方向（Screen Direction）

同一段运动，方向必须连贯。

- A 从右出画 → 下一镜应该从左入画（他继续往同一方向走）。
- 反过来（从右出、从右入）= 方向跳变，观众以为他掉头了。
- 运动轴线：运动主体形成的线，机位同样要在同一侧。

### 5 · 动作匹配（Match on Action）

一个动作跨两个镜头完成——前一镜动作做一半就切，后一镜接着做完。

- 这是隐藏剪辑点的最强手段（＝铁律 1「切在动作中间」的底层原理）。观众的注意力在动作上，注意不到切。

### 6 · 越轴的合法方法（想故意越轴时）

越轴不是绝对禁忌，但必须给观众一个「重新定位」的台阶：

| 方法 | 做法 |
|---|---|
| 骑轴镜头过渡 | 先插一个 ⑧⑨ 骑轴镜头（视线正对相机），观众失去方位感，再越轴 |
| 插入空镜头 | 插一个环境空镜，观众遗忘位置关系后，自然换侧 |
| 摄像机运动越轴 | 镜头连续运动绕过轴线（观众跟着转，能理解） |
| 插入第三者 | 出现第三个人，重新建立关系轴线 |
| 通过大动作剪辑 | 一个剧烈的动作（爆炸、撞击）遮住越轴 |

没有台阶的越轴 = 无技巧越轴 = 观众懵。演出意图再强，也要先给台阶。

### 7 · 主镜头（Master Shot）与建立镜头

- 每场戏先给一个建立镜头（远景 / 全景），交代这是哪、谁在哪、什么关系。之后再上中景 / 近景 / 特写。不给建立镜头就切特写 = 观众不知道身在何处。
- 打斗戏同理：开场给一个能看清两人距离与方位的镜头（＝对轰的 ① 关系镜头）。
- 大位移之后也要重新建立：人飞出去了，必须让观众知道落到哪、离多远。

## 一、镜头语言库（15 种，可单用可组合）

核心放开：不再只有硬切——镜头可以动，可以推、拉、摇、移、升降、环绕、变焦。
铁律 9 的「一律硬切」改指「切与切之间是硬切」（不许 dissolve / fade / morph），不再限制镜内运镜。

| 镜头语言 | 用法 | 写法 |
|---|---|---|
| 希区柯克变焦（Dolly Zoom / Vertigo Shot） | 相机移动同时变焦，背景拉伸／压缩，表现冲击与心理震颤 | `the camera dollies back while zooming in, the background stretching away` |
| 英雄式镜头（Hero Shot / Low-Angle） | 低角度仰拍，让角色强大、有支配感 | `low-angle shot looking up at the figure, dramatic sky behind them` |
| 快速摇摄（Whip Pan） | 极快水平摇摄，运动模糊，用于转场或表现能量 | `the camera whip-pans to the right, motion blur streaking across the frame` |
| 快速变焦（Crash Zoom / Snap Zoom） | 极快变焦，视觉冲击，用于强调 | `the camera crash-zooms into the detail` |
| 跟踪镜头（Tracking Shot） | 相机跟随主体，保持主体在画面中 | `the camera tracks alongside the fighter, keeping him in frame` |
| 升降镜头（Crane Shot） | 相机在机械臂上升降，壮观弧度 | `the camera cranes up, revealing the full scale of the battlefield` |
| 弧形镜头（Arc Shot） | 相机绕主体圆周运动 | `the camera arcs around the fighter, revealing his profile` |
| 长镜头（Long Take / Oner） | 不切镜头，连续拍完整场 | `the camera never cuts, following the action in one continuous take` |
| 斯坦尼康（Steadicam） | 稳定器拍摄，平滑移动 | `the camera moves smoothly on a steadicam, gliding through the scene` |
| 手持（Handheld） | 手持拍摄，自然晃动 | `the camera is handheld, shaking with the impact` |
| 推入／拉出（Push In / Pull Out） | 相机向前或向后移动 | `the camera pushes in on the fighter's face` |
| 荷兰角（Dutch Angle） | 相机倾斜，不稳定感 | `the camera tilts at a dutch angle, creating unease` |
| 极端仰拍（Extreme Low Angle） | 贴地向上仰，拍庞然大物专用 | `the camera tilts up from an extreme low angle` |
| 第一人称 FOV（POV / FPV） | 观众用一具正在动的身体在看，带广角畸变与运动模糊；冲刺、坠落、闪避专用 | `a first-person viewpoint hurtling forward, the edges of the frame warping with the speed` |
| 夸张透视后拉（Dramatic Pull-Back） | 一边保持主体在画面里一边急速后拉，把空间纵深整个撑开；交代大场景与体量 | `the camera pulls back rapidly while keeping the figure centered, the space stretching open around it` |

两个补充写法（通用）：
- 超视距俯瞰视角：切换到俯瞰战场的广角镜头，一次性交代全局位置关系
- 动态追踪运镜：镜头跟着技能 / 身体从高空冲下来，观众像自己在飞

用法要求：至少用 3 种，且逐镜不同——景别与机位互不相同，这同时是铁律 9 的防融合防线。

## 二、动作蒙太奇（5 种）

| 技法 | 做什么 | 用在哪 |
|---|---|---|
| Cutting on Action | 在动作中间切镜头，观众注意不到剪辑痕迹 | 所有打斗的默认切法（＝铁律 1） |
| 三镜头法 | 启动 → 爆发 → 结果，三个镜头表现一个完整动作 | 重击、大招、决定性一击 |
| 十字景框 | 重要视觉元素留在画面中心，切换时仍能辨认 | 快剪段落（切得越快越需要） |
| 视觉重叠 | 不同机位保留同一动作的冗余帧，产生「多重冲击感」 | 想强调「这一下更快更狠」时 |
| 节奏性断层 | 删掉中间帧，只留「起点」与「终点」 | 想制造癫狂、失控感时 |

三镜头法的细节（武侠片剪辑传统）：三个镜头分别取「动作启动 → 力量爆发 → 动作结果」三个最有代表性的片段，不客观完整地表现动作全过程——既缝合切换痕迹，又压缩冗余、加快节奏。镜头 2 必须清晰显示击打真的发生了（不被身体或物体遮挡），必要时用细部特写。

## 三、剪辑节奏：快慢交替 + 压迫与留白

- 快慢节奏交替：正面缠斗时镜头飞速切换（生死一线的紧绷感）；关键瞬间立刻慢放（蓄力 / 寻找破绽 / 决定性一击）。全程匀速快切 = 疲劳，必须有快有慢。
- 压迫感与留白的交互：不是一味地切。紧张段落之后要有一个呼吸镜——灾难前夕的静止、命中后的余波、两人对视的一瞬。留白是下一次爆发的起跳板。
- 镜头之间不拖沓：镜头长度由内容决定，不凑时长；一个动作交代完就切走（＝铁律 1）。
- 特写与远景交替：远景给规模与位置，特写给力量与情绪。只给远景 = 看戏；只给特写 = 晕。

## 四、空间转换必须交代

- 从地面到天上的转换，必须用镜头语言明确交代——不能一个硬切就从地面到了空中。
- 写法：`the camera tilts up from the deck to the sky, following the fighters as they rise`、
  `the camera cranes up, revealing the full scale of the battlefield`
- 判据（一句话）：观众看完这一镜，能说出「他们是怎么上去的吗」？说不出来 = 没交代，必须补一个交代镜。
- 同理适用于：地面 → 空中、空中 → 地面、场景 A → 场景 B 的位移。位移越大，越需要交代；大位移（几百米、跨场景）必须有一个镜头专门交代。

## 五、人物与动作的物理

### A · 动作要有物理逻辑（不是凭空挥剑放技能）

- 有招式：动作有起势、有走完的弧线（＝铁律 11 挥满三段）
- 有借力：发力有来源——蹬地、转腰、反作用力；不是凭空出手
- 有反馈：打中对方有反应，被架住有反震，落地有冲击
- 战力分层：不同层级的角色，动作质感不同（低阶靠技巧与动作，高阶靠气度与法则）
- 环境互动：动作会对周围环境产生扰动（掀尘、裂地、震落物），不是独立于环境

### B · 布料 / 头发 / 饰品必须随动作动

一样都不动 = 人像木偶 = 违规。（规则全文是 `iron-rules.md` 铁律 14——默认真实、强度跟随环境、不用用户提醒；本节只管写法细节。）

- 高速移动时：头发被风吹向后、衣服被吹得贴身、饰品随动作摆动
- 动作要有惯性：启动时有加速、停止时有减速、转向时有离心力
- 动作要有重量感：跳跃有落地、落地有冲击、冲击有反馈
- 动作要有连贯性：前一个动作的结果是后一个动作的起因，不是彼此独立的
- 写法：`his hair whips backward in the wind`、`her clothing flutters with the movement`、
  `the pendant swings with the motion`

## 六、本文件加查（在 21 项之外）

先查逻辑（地基），再查语言（花活）——逻辑错的片子，语言再花也救不回来。

1. 轴线：全片始终在轴线同一侧吗？有无越轴？越轴是否给了台阶？
2. 建立镜头：每场戏、每次大位移之后，是否重新建立空间？
3. 30° 规则：相邻两镜拍同一主体时，角度变化 ≥ 30° 或换了景别？有无跳切感？
4. 视线匹配：A 看画外的方向与下一镜目标的方位对得上吗？
5. 银幕方向：出画 / 入画方向连贯吗？（右出应左入）
6. 动作匹配：切点落在动作中间、跨镜完成一个动作吗？
7. 镜头语言：至少用 3 种，且逐镜互不相同；有运镜，不全是静切
8. 游戏视角 0 命中（铁律 12）
9. 动作蒙太奇：至少用 2 种技法（Cutting on Action 必用，另加至少 1 种）
10. 剪辑节奏：有快有慢，不是全程匀速快切；留了呼吸镜
11. 空间转换：每次大位移都有交代镜；观众能说出位移怎么发生的
12. 人物物理：布料 / 头发 / 饰品逐镜都在动；有惯性、重量感、连贯性（铁律 14 ②：风力档位逐镜答得上）
13. 表情克制（铁律 14 ①）：全片无夸张表情、无 AI 式法令脸；面部肌肉从不用力；情绪走身体不走脸

## 附录 A · 景别表（文戏与通用剧情用）

| 景别 | 缩写 | 画面范围 | 典型用途 |
| --- | --- | --- | --- |
| 大远景 | ELS | 人物极小，环境为主 | 开场建置、孤独感、史诗收束 |
| 远景/全景 | LS/FS | 全身+环境 | 交代人物位置关系、调度全景 |
| 中景 | MS | 膝/腰以上 | 对话主体镜头、动作交代 |
| 中近景 | MCU | 胸以上 | 对话正反打常用，情绪渐显 |
| 近景/特写 | CU | 脸部 | 情绪高点、反应镜头 |
| 大特写 | ECU | 眼/唇/手/物 | 关键道具、极强情绪、insert |
| 过肩 | OTS | 一人肩后看另一人 | 对话戏建立空间关系 |

景别递进原则：进入新场景一般「远 → 近」建立空间；情绪上升「松 → 紧」；高潮后「近 → 远」释放。相邻同主体镜头景别至少跨两档或机位夹角 ≥30°，否则产生跳切感（除非刻意跳切）。**⚠️ 此条已升格为硬规则，全文与自查见 `iron-rules.md` 铁律 12「相邻镜硬规则」（2026-09-28 用户实测抓出）。**

## 附录 B · 运镜词汇表（大白话口径）

固定、推（推进强调）、拉（拉远释放）、摇（左右环顾）、移（平行跟随）、跟（尾随主体）、升降（气势变化）、环绕（关系/情绪外化）、手持（纪实/紧张）、甩（whiplash，突发转向）。

默认原则：情绪平稳用固定或缓推；紧张用手持/跟拍；揭示用推；收束用拉或升。每镜只写一个运镜。打斗戏的运镜库以本文一节的 15 种为准。

## 附录 C · 剧情类型 → 分镜模式对照表（文戏与通用剧情）

| 剧情类型 | 分镜模式 | 要点 |
| --- | --- | --- |
| 双人对话 | 建置双人中景 → 过肩正反打 → 特写收情绪点 | 严守关系线；反应镜头（听话人特写）和说话镜头同等重要 |
| 三人以上对话 | 全景定桌位 → 轴线取主导两人 → 单人近景轮换 | 先声明谁与谁是主轴；次要角色用插入近景 |
| 追逐 | 远景定相对位置 → 跟拍（移/手持）→ 交叉剪辑追逐双方 | 双方屏幕方向必须一致；用特写（脚步/表情/道具）调节奏 |
| 揭示/悬念 | 角色近景 → 推镜或视线匹配 → insert 揭示物 → 反应特写 | 信息顺序即镜头顺序：看的人 → 看到的东西 → 反应 |
| 动作打斗 | 中景定招式设计 → 多角度拼接关键打击 → 大特写打击点 | 每镜只交代一个动作单元；快慢结合（慢动作只给关键一击）；动作描述必须按 `action-physics.md` 写发力链 |
| 抒情/回忆 | 空镜（场景无人）→ 大远景人物 → 细节特写蒙太奇 | 可弱化轴线；靠质感词与音乐统一情绪 |
| 转场过场 | 运动匹配剪辑 / 空镜 / 大远景 | 一个镜头交代时空转换即可，不拖 |

> **本表按「剧情类型」切；若按「情绪」切（紧张 / 悲伤 / 恐惧 / 心动…该调什么景别·角度·运镜·节奏），见 `emotion-to-camera.md`。**

## 附录 D · 机位四要素（每镜必写，缺一项即返工）

每镜写全四项：**拍摄方位 · 拍摄高度 · 运镜（附录 B）· 画面位置**。不写 = 模型在正/背/左/右之间自由发挥（实测事故：同一镜头三次生成三次朝向不同）。

**拍摄方位**（以角色面朝方向为 0°，水平环绕角色，斜侧必须写明左右）：

| 方位 | 说明 |
| --- | --- |
| 正面（0°） | 直面面部，连接感强、立体感差，对称构图 |
| 斜侧（前 45°，写清左右，如「左前 45°」 | 最常用，表情与立体感兼顾 |

| 过肩（OTS） | 隔另一人肩拍，对话戏默认，写明过谁的肩 |

**拍摄高度**：平拍（眼平，中性默认）· 俯拍（高角度，角色显弱小/被审视/交代空间）· 仰拍（低角度，角色显强大/压迫）· 顶拍（鸟瞰，正上方）· 贴地（虫视）· 荷兰角（倾斜，不安混乱，慎用）。

**画面位置**：主体画左/画右/居中/三分点；双人写相对位置（A 画左、B 画右）；人物视线与运动方向前留白（look room / lead room）；正反打两镜中同一角色的画面位置必须一致。

**从调度图翻译**：方位与画面位置由俯视调度图推算——相机在角色面朝方向的哪一侧多少度、角色面朝画左还是画右，逐镜算清再落笔；与同场景其他镜头共用机位区，不越轴。
