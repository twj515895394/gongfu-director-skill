## 1. 气流、风压、尾流与冲击波

- **气流的可见载体。** 先确定尘、雾、沙、雨、树叶、衣发、植被、水面等已有载体。方向由源点和场景通道确定；轻物先响应，固定端限制衣物，墙角和障碍后可出现绕流/回卷。持续风与一次冲击分别写，不能所有物体同幅同相摆动。
- **尺度和形状。** 大范围风场有总体推进，局部细涡沿边缘、障碍或剪切处发展。喷流先有定向主体，再随距离扩散/卷吸；不能一出源点就均匀炸成球形烟花。受物体运动产生的尾流落在其路径后方，不永远贴在画面中心。
- **压力不等于实体白环。** 可通过尘面依次掀起、柔性物受压、水面外扩波纹、短暂背景折射表现压力前沿；凝结壳、发光环或可见空气透镜须有湿度/能力/美术设定支持。压力前沿与随后被搬运的尘土不必重合，不让风压默认携带热与火。
- **收束。** 冲击过后主体位移或继续顺风，游离衣角和小涡衰减，细尘可滞留。持续风则继续供能，不强制落定。
- **避免。** 多条等宽白丝带代替空气、整片背景一起橡皮扭曲、无来源的龙卷、轻尘和重石同轨、风还没抵达对象就全体响应。用户明确选择漫画风线或魔法缎带时保留该造型，改进其空间遮挡与时间结构。

## 2. 粒子、火星、灰烬、尘粒与武器拖尾

- **先命名材料。** 金属火星是可冷却的炽热碎屑，灰烬轻而飘，石屑有断面和碰撞，水滴反射/折射，尘粒主要受光；能量微粒的运动/发光按设定。粒子只是表达方式，不是统一材料。
- **分群而非均匀撒点。** 按源点、发射扇区、大小/形状、起速、寿命组织疏密，保留少量可跟踪的主碎片。变化与原因相关：近接触区密、沿受力方向展开、碰地后有适当反弹或滑动。不要用无依据的随机性打散全部方向。
- **速度与寿命。** 阻力使轻小颗粒容易随风，部分碎片保持弹道；炽热材料颗粒可逐渐冷却失亮，魔法或其他非热发光粒子按其供能/寿命设定消退。闪烁可有变化但不每帧凭空更换位置。拖影长度随速度与曝光关系改变，不每点附一条同长尾巴。
- **武器弧光。** 若设定需要，拖尾由刃尖/刃缘的真实路径留下，新端跟随武器、旧端按寿命衰减；挥击加速与停顿改变弧长。它不能穿过并未经过的空间，不能从头复制第二把实体武器；碰撞火星只在实际接触处发生，明确落空不产生命中爆闪。
- **避免。** 所有尘埃自发光、粒子全屏等密等大、石屑像纸片、无源星点、同时出生同时透明消失、每次挥动都铺满一张发光扇面。用户明确的整齐星阵或粒子图案按其编排保持。

## 4. 火、烟、爆炸、蒸汽与热扰动

- **选择燃烧情境。** 火炬、喷焰、表面燃烧、燃料爆发和无火机械爆裂不同。火受燃烧区域、供给和流动制约；不能所有爆炸都长成同一个汽油火球，非燃烧破坏不默认起火。无烟火焰与有烟燃烧按材料/设定区分。
- **大形与细节。** 主火团或火舌先有方向，随后卷动、拉伸、断续；边缘细裂从流动发展，内部不会逐帧像沸水噪点洗牌。爆发可以先快速膨胀，随后整体翻卷/上升并受风推移，不把整段变成匀速放大的球。
- **密度与发光。** 燃烧区域有亮度组织，烟的厚处遮蔽内部，局部热光可从较薄裂隙透出；外围照明随体积遮挡变化。是否明亮核心、暗烟壳取决于现象，不把所有蒸汽都染成黑烟。大烟团的翻卷与细缘速度层次服务尺度。
- **耦合。** 冲击、结构破碎、碎屑抛出、烟尘卷起按同一事件组织；碎片穿过尘烟可带动局部流动，后续坠落可产生新的局部尘扑。短片只选择可容纳且影响叙事的次级事件。
- **热和蒸汽。** 热扰动是局部背景折射，强度与热区/视线长度有关；不在整幅贴透明水纹。水蒸气本身通常不可见，可见白雾来自凝结液滴；实际提示词只需写冷凝雾/白汽的形态与消散，不给模型科普。蒸汽可被遮挡、吹散，并不自动发光。
- **余波。** 供给停止后火焰衰退与烟尘滞留可以不同步；燃烧、冷却、烟散速度由情境决定，不强制在一镜内归零。保留焦痕、局部余火等已发生结果。
- **避免。** 棉花球、整团同亮、同尺寸蘑菇团重复、亮红烟雾替代火、火星和烟同速、无燃料仍无限追加火球。美术化魔火可有非常规颜色/浮力，但其形态和世界作用要一致。

## 6. 闪电、电弧与电气故障

- **拓扑有主次。** 区分天空闪电、导体间电弧、沿表面爬行和魔法电流。定义端点或主通路、主要分支与短寿命细枝；主亮通道和分支不必同宽同亮。雷暴可以有重复击闪，电弧可以变化，不是每帧随机画一张无关联锯齿网。
- **连接与接触。** 电气效果按导体、绝缘间隙、接地或已设能力确定路径，不能无解释地永远追踪最近人脸。持续电弧的端点可滑动，但要依附真实表面和运动。能力无现实导电限制时尊重设定，不假装提供工程安全参数。
- **光和材料。** 短促闪光照亮周围可见表面；局部烧蚀、火花、冒烟只在强度和设定支持时出现。细电光不必把整座城照成白昼，巨型闪电也不需要全景每处等亮。
- **节奏与声。** 闪击与雷声按距离组织，近处电弧的爆裂/嗡鸣跟随启停。电光熄灭后反光同步退去，损伤若已产生则保留。
- **避免。** 橡胶管闪电、全体同频闪烁、没有起止点、无限分叉填屏、把电流和金属火星视为同一材料。

## 7. 物理破坏、地裂与材料失效

先标实际作用区、结构厚度/支撑、材质和允许破坏范围。接触附近的崩裂、弯曲或脱离说明受力，后续失效沿结构发展；大范围瞬时冲击也须有来源，不强迫全部慢慢裂开。完整结构、主破块、细屑与粉尘各有职责。

| 材料/结构 | 优先选择的可见行为，按实际构造调整 |
|---|---|
| 石材、混凝土 | 冲击局部压碎/剥落，裂缝连接薄弱处，大小不一的块体带有断面厚度；钢筋只在已设钢筋混凝土中露出、牵连或弯曲 |
| 砌砖、砌石 | 接缝与砌块共同决定脱落，墙段可能先倾斜再散开；保留尚有支撑的部分，不能全墙同时成砂 |
| 木材 | 顺纹劈裂、长短不一的木刺，连接处松脱或断裂；受力构件先弯曲还是直接断裂由条件决定 |
| 金属 | 局部凹陷、折弯、屈曲、撕裂或接头断开，保持板厚与金属反光；材质/温度不支持时不能像陶瓷一样碎成均匀小块 |
| 玻璃 | 按普通、钢化、夹层及安装方式选择裂纹、碎片尺寸、框内残留或膜层牵连；不宣称所有玻璃都碎成长刀片 |
| 土、沙、岩层 | 土可结块/塌落，沙可滑移和颗粒流，岩层沿结构断裂；扬尘来自可被扰动的细料，不在每块洁净石面凭空爆烟 |
| 冰 | 裂纹、浑浊断面、透明薄缘与碎片相区分，厚板和霜层不同；不自动像玻璃、也不无因发光 |

- **传播与后果。** 墙被击穿后有洞口/背面碎落，地面抬起后有错台/坑缘，支撑失效后构件沿可推导路径倾倒。倒向要由剩余支撑、重心所在侧、已发生的倾转/动量或持续外力解释，不能只凭“失去支撑”任意指定方向；跨镜保留决定倒向的可见状态。无因随机预裂网不能代替受力；没有被破坏的区域继续存在。
- **质量和运动。** 主块保留受冲击后获得的初始速度/旋转，与地面或其他块体碰撞，再反弹、滑移或停住；细屑与尘受阻力不同。给少数重要块体可跟踪路径，不要求每颗碎片编轨迹，不使用“大块必先落地”的错误规则。
- **烟尘不隐藏拓扑。** 接触时可有短促粉扑，但关键断裂/洞口/坠落至少有可读窗口。尘雾之后留下与破坏范围相容的缺口、裸露内层和碎块，不能切镜后墙自动修复或地面只剩一张烧焦贴图。
- **材料声音。** 硬脆崩裂、木裂、金属扭曲、重块落地与细屑弹落分别有声源；不要统一为一次电影爆炸声。
- **避免。** 所有材质同一种碎块、等大多面体均匀四射、无厚度纸片、受击点与裂纹起点不符、整楼无支撑变化凭空垮塌、碎片落地仍永久弹跳、尘消失后无损伤。用户要求无残留或魔法复原时按其规则显示变化。

## 8. 冰霜、结晶、沙尘与地表变化

- **生长有前沿。** 冻结、结晶或侵蚀从已设接触/能力作用处推进；沿表面爬行、向外生长、从内部裂出是不同过程。指定生成形状与厚度，不把整片场景一帧切换成蓝色材质。
- **冰与霜分开。** 薄霜是细小附着，厚冰有体积与透射/散射，霜雾是空中凝结物；三者可同时出现但不是必选套件。湿润、冻结与融化的先后按场景，不给任何冷光默认添加白雾。
- **沙与粉尘分开。** 重颗粒可贴地跳跃/滑移，细尘随风悬浮；沙堆形成堆积与滑落面，尘墙有前沿和浓淡。不能把沙暴等同棕色烟团，也不能每粒沙都闪金光。
- **接触与持久性。** 覆层附着于实际表面，门缝、轮廓或关节受其厚度影响；地形改变后高差和通道持续。高亮晶面随视角改变，内部纹理不随机爬动。
- **避免。** 一键全场染色、晶体尺寸全同、冰无厚度、沙无堆积、增长速度/方向切镜重置。魔法瞬时生成允许，但前后结果与设定一致。

## 9. 雨、雪、雾、云与大气

- **统一环境驱动。** 风向、降水方向、烟尘和衣物服从同一世界风场，局部遮蔽和回流可以不同；不能全场不同系统各吹各的。雨滴和雪片因形状、阻力等表现不同，雪不全是匀速白圆点。
- **空间层次。** 前中后景降水在尺寸、清晰度和遮挡上合理分开，远处密集降水可汇成空气层；不在每个深度铺相同屏幕贴图。雾与云的密度按高度、区域和形状变化，厚处遮蔽、薄处透景，云的受光边缘与内部暗部有体积。
- **表面响应。** 雨落水面有局部涟漪，落硬地有适用溅点/水膜，檐下遮雨，湿痕与积水随时间发展；雪在合适表面堆积或融化，不能不分温度/材质永远附着。只写镜头需要的响应，不强迫每场雨特写水滴。
- **光照。** 光柱由光源、遮挡和参与散射的介质共同决定；浓雾会影响远景反差和光线穿透，不是简单全屏灰滤镜。日景、夜景和逆光有不同读法；不默认每片薄雾都是发光蓝雾。
- **避免。** 雨穿屋顶、雪无视遮挡、云纹理原地沸腾、镜头一动雾跟着屏幕走、雷光与场景受光分离、全景锐度一致。持续天气无需专门起势/消散，更不能给安静文戏自动添风暴。

## 类别外的效果与混合效果

新效果先判主介质与能力规则，再选最相关的两类关系：例如熔岩是高温黏性流体及冷却壳，不能直接拼“水 + 火 + 石头”三套全长描述。一个镜头有多种效果时，选决定剧情的主效果；次级效果解释它对世界的影响，背景效果维持空间。保留各自的材料身份与时间状态，避免所有层一起变亮、一起爆开、一起消失。
