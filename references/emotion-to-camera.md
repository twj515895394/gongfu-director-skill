## 情绪靠四个旋钮调节

任何情绪都由四个变量合成，调这四个就够了：

| 旋钮 | 往左（冷 / 远 / 松） | 往右（热 / 近 / 紧） |
| --- | --- | --- |
| **景别** | 远景 → 孤立、渺小、宿命 | 特写 → 亲密、共情、压迫 |
| **角度** | 俯拍 → 弱、被审判 | 仰拍 → 强、威胁、崇高 |
| **运镜** | 固定 / 缓拉 → 冷静、疏离 | 手持 / 推 → 紧张、代入、逼近 |
| **节奏** | 长镜 / 慢切 → 沉思、压抑、真实 | 快切 / 短镜 → 混乱、兴奋、失控 |

**铁律：四旋钮必须指向同一个情绪。互相打架 = 视觉噪音。**（photoshipone：moving because the equipment allows it 是最常见的错误；没有动机的运动就是噪音。）

## 情绪 → 手法映射表（主表）

| 情绪 | 景别 | 角度 | 运镜 | 节奏 | 代表作例 |
| --- | --- | --- | --- | --- | --- |
| **紧张 / 对峙** | 中景 ↔ 过肩正反打；权力转折时切单人 | 一场里仰 + 俯交替（谁掌权给谁仰角） | 慢推（推向被动一方）· 环绕（权力洗牌） | 长镜蓄势 → 突然甩镜 / 快切兑现 | 《黑暗骑士》小丑低角；《社交网络》构图权力转移 |
| **愤怒 / 爆发** | 逼近中的中近景 → 爆发点大特写（手 / 青筋 / 眼神） | 低角（压迫）· 荷兰角（失控） | 手持 / 快推 | 短促快切，1 秒内多镜 | 国内教程「冲突瞬间切特写，一远一近冲击力翻倍」 |
| **悲伤 / 压抑** | 特写（眼 / 手 / 物）与远景交替 | 俯角（无助） | **固定长镜** / 极缓推 / 缓拉 | 长镜 ≥10s，ASL 拉长 | 《海边的曼彻斯特》；eathealthy365「长静止镜头迫使观众与情绪共处」 |
| **孤独 / 疏离** | **大远景**，人物占比极小，负空间大 | 平拍或略俯 | 静止 / 极缓横移 / 缓拉（把人丢在环境里） | 长镜、留白 | 《她》《迷失东京》《银翼杀手 2049》；Deakins 27mm 深焦让猎人猎物都成小点 |
| **恐惧 / 不祥（dread）** | 从宽景逐步收窄；POV 代入 | 荷兰角（不安）· 低角（威胁） | 慢推 / 长轨跟 / **推轨变焦（dolly zoom）** | 缓慢积累 → 静止后一次爆发 | 《闪灵》长轨；《大白鲨》dolly zoom |
| **心动 / 亲密** | 特写、双人镜；浅景深隔离世界 | 平视 / 略仰 | **缓推**（增加代入）· 极缓靠近 | 长镜、慢切、留白停顿 | 《月光男孩》；filmvision「缓慢推 / 拉跟随情感节拍」 |
| **震惊 / 顿悟** | 特写 / 大特写 | 平拍 | **推轨变焦**（天旋地转）· 急推 | 一拍到位 | 《迷魂记》《大白鲨》，俗称「希区柯克变焦」 |
| **绝望 / 崩溃** | 近景与「巨大人小」的远景交替 | 略俯（渺小） | 手持不稳 / 长镜不切（无处可逃） | 长镜持续压 → 或快速蒙太奇 | 《人类之子》长镜；《梦之安魂曲》快剪 |

**读表方法**：先定情绪 → 取一行 → 四个旋钮一次性对齐 → 再回 `camera-language.md` 附录 D 写机位四要素。

## 三条底层规律（比逐条映射更值钱）

### 规律 1 · 情绪不靠脸，靠「身体和行为的变化」

抽象情绪必须改写成可拍的反应，否则落不到镜头语言上：

| 情绪 | 可视化反应（写进 prompt 的就是这些） |
| --- | --- |
| 悲伤 | 沉默 · 闪躲 · 停顿 · 微微发抖 · 说不下去 |
| 恐惧 | 动作停住 · 呼吸变化 · 视线搜索 · 退后半步 · 手指收紧 |
| 愤怒 | 逼近 · 压低声音 · 肌肉绷紧 · 眼神不移开 · 动作变直接 |
| 心动 | 停顿 · 对视时间变长 · 声音变轻 · 下意识整理自己 · 视线来回 |

→ **这是铁律 14（情绪走身体不走脸）的外部理论依据。** 写法上和你 skill 的微表情库（`action-physics.md`）同源，可互相印证。

### 规律 2 · 最有戏的是「动作前的那一下停顿」

> 「她准备说'没关系'，但开口前停了一下；他想离开，却在转身前没有立刻走；她伸手去拿东西，但手停在半空，迟迟没有落下。」

停顿让观众意识到「角色心里有东西」，**比直接哭出来 / 喊出来更容易形成情绪张力**。

→ **这条直接对应铁律 3-补 的时长下限**：情绪镜偏赶的根因，往往不是镜头数多了，而是**没给停顿留时间**。动作只占节拍的一半，另一半是停顿。

### 规律 3 · 用空间关系代替表情

人物之间的距离本身就是情绪信息：

- 明明在对话，中间隔着一张桌子
- 明明同框，一个在前景一个在远处
- 明明是亲密关系，镜头却故意拉开
- 明明有人想靠近，对方却后退半步

→ **这条可以直接写进调度（`blocking-diagram.md`）**，不必全靠脸表达；对无对白的情绪段尤其有效。

## 情绪节奏量化参考

### ASL 三档（平均镜头时长，行业通行口径）

ASL = 总时长 ÷ 总镜数。这是行业公认的节奏指纹：

| 类型 | ASL | 例 |
| --- | --- | --- |
| 动作片 | **2–4 秒** | 《疯狂的麦克斯 4》≈2.7s；《谍影重重 2》≈2.4s |
| 经典好莱坞 | 8–12 秒 | — |
| 剧情 / 文艺 | **常 >10 秒** | 《2001 太空漫游》≈13s；《老无所依》刻意拉长 |

→ **对本 skill 的意义**：铁律 3「打斗 ≥ 1 镜/秒」≈ ASL 1s，比行业动作片还紧；铁律 3-补「文戏 1.5–2.5s / 镜」≈ ASL 2s，**行业文戏比本 skill 还慢**。所以现有口径是**偏保守安全**的，不需要放宽。

### 情绪镜时长公式（短视频口径）

| 段落 | 单镜时长 |
| --- | --- |
| 开篇钩子 | 0–3s，短特写抓眼 |
| 温情叙事 | 2–4s，慢节奏走心 |
| 冲突转折 | 1s 快速切换 |
| 结尾升华 | 5–8s 长镜留白 |

### 情感对话要「给停顿」

> 「人物说完话立马就切，对情感表达是不够的……情感是需要时间的。」

规则：**情感关键点那句台词之后，不要紧跟下一句**，要留出空白停顿（给听话人的反应镜，或给说话人自己的余韵）。这也是为什么文戏台词镜不能切碎。

## 六镜情绪递进公式（可直接套用）

国内教程里现成的结构，和 Ref2VA 分段天然对齐：

> 远景（交代环境）→ 全景（人物行动）→ 中景（动作互动）→ **近景 / 特写（情绪支点 · 核心共情镜）** → 中景（承接延续）→ **缓拉远景（收尾留白）**

**配套禁令**（与本 skill 铁律撞车，故重申）：
- 禁止连续 3 个远景 / 大全景顺剪（画面没有松紧节奏）
- 对话戏不许缺中景、缺过肩正反打
