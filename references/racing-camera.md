> 定位：题材级镜头语言，挂在导演层。13 条铁律全部照常适用——本文件只解决「赛车戏怎么拍才快、才真、才电影」，以及这个题材自己的头号陷阱。
> 头号陷阱先说：赛车游戏的追尾相机（吊在车尾后上方焊死跟随）是这个题材最容易滑进去的死法——那是铁律 12 的禁项，不是电影追拍机位。

## 一 · 参考源（用户点名白名单；只取机位 / 运动 / 节奏，不取桥段与人设）

| 片子 | 年份 | 内化要点 |
|---|---|---|
| F1 | 2025 | 真速优先：追拍车 / 拖车架追不上真车速就别用；后期提速只许「一点点」，提过头人物像布偶；蓝棚/体积棚没动能——全否。单车最多 16 个车载点位（车头 / 尾翼 / 侧箱 / 座舱），遥控云台可在镜内从车手 POV 摇到车手脸（一个机位两种用途）。禁 IBIS：防抖会跟车身震动打架毁画面——震动是信息，不是噪声。升格空镜用直升机不用 FPV（要重量感）。拍摄窗口是真实赛事空档，3–15 分钟一段抢拍。 |
| 飞驰人生 2 | 2024 | FPV 穿越机 = 山路窄道主力：窄路只容一车、跟拍车进不去还扬尘毁画面；穿越机能避障 / 贴地 / 逼近特写。转场长镜范式：车内机械臂精准走位 → 拉出窗外 → FPV 接住漂移状态的车身。对撞测试：800fps 高速机挂穿越机全程跟拍、周边十几机位布置、只此一次。综合节奏：航拍壮阔（峡谷 / 迂回赛道）⇄ 特写快切 ⇄ 升格舒缓，快切叠到高点再泄。制作组点名的细节：车身压缩、轮胎与地面摩擦。 |
| 速度与激情系列 | 2009– | 俄式臂（高性能追拍车上的陀螺稳定摇臂）= 横移扫拍主力，可升降可大范围扫。中柱特写传统：拆掉车身上半截，镜头离演员 4 尺，正对方向盘 / 挡杆 / 脚。低角度 = 力量感；慢门要背景拖影。静机穿越：锁定机位让车呼啸穿框——用固定参照物「证明」速度。长焦压缩：让追兵 / 障碍显得贴脸。 |
| 极品飞车 | 2014 | 实拍优先；直升机低空贴飞；轮对轮 proximity 交换前后的语言。 |

候选（用户可删）：极速车王 2019——车手面孔特写与轮胎尖叫特写交替；GT 赛车 2023——模拟器 POV 的座舱语言。

速度错觉通用科学（不分片，直接当规则）：感知速度 = 相对速度 + 视差 + 参照物，不是实际车速。前景物体离镜头越近、掠过越快，画面越快；主体小、背景大 = 显慢；换参照物 = 换速度感。

## 二 · 机位库（每条 = 方位 / 高度 / 距离 + 为什么；每镜按蒙太奇接点重选，铁律 12 照旧）

A. 贴车组（速度感最强）
1. 贴地轮拱 / 侧裙机位——离路面几十公分、装在车身侧面朝侧前。为什么：路面标线 / 碎物贴着镜头呼啸而过，前景视差拉满。
2. 前保险杠 / 格栅机位——超广角朝前贴车头。为什么：路面与远方扑面而来，Z 轴逼近感最大。
3. 座舱 POV——朝前，方向盘 / 手 / 挡杆入画。为什么：人的在场，速度有主体。
4. 车手脸特写——从中柱后 / 侧窗拍脸。为什么：速度写在人脸上（眼 / 手的小动作）。
5. 车尾朝后机位——装尾翼 / 车尾朝后。为什么：追兵 / 来车入画，攻防关系一目了然。

B. 追拍组
6. 俄式臂追拍车——平行并跑横移扫拍，可升降、可大幅扫转。为什么：只有它能以车速并跑且镜头是活的（追拍车自身必须够快，理由见 F1 真速优先）。
7. 反向 / 相向掠过——镜头车与被摄车对开。为什么：相对速度翻倍，一镜顶两镜。
8. 静机穿越——锁定机位让车呼啸穿框。为什么：给观众一个固定参照物，速度被「证明」；也是连续跟拍三镜后必须出现的节奏对比。

C. 空中组
9. 直升机侧飞 / 贴顶——与车同速低空并飞。为什么：有重量感的大幅运动（FPV 太轻，撑不起史诗段）。
10. FPV 穿越机——窄路 / 林道 / 隧道 / 桥洞里唯一能贴地穿梭的活镜头，可逼近到米级特写。为什么：其他机位进不去的空间只有它进得去。必须有电影逻辑（为什么这里要穿、要去哪），不许无锚点空穿。
11. 高空大俯拍——一次性交代赛道形状 / 双方位置 / 剩余距离。为什么：地理重建（追逐地图）。一镜即收，不连用。

D. 弯道组
12. 弯心 / apex 机位——架在弯道外侧，车甩尾入画再出画。为什么：过弯是赛车的动作高潮，apex 就是蒙太奇接点。
13. 长焦摇摄（pan）——远距离摇着跟。为什么：长焦横摇是二维运动，背景被匀速拉平——故意杀视差，做速度对比用。
14. 路侧低角仰拍——贴地面朝上。为什么：飞跃 / 跳台时车从头顶掠过，重量与威胁最大化。

## 三 · 速度感语汇（铁律 13 的四条载体照旧 + 赛车专属八条）

四条载体照旧：motion blur（背景拖成糊、主体清楚）· 元素拖尾（尘 / 水雾 / 火花自己拖形）· 残影（配额不变：单镜 ≤ 2 道、全片 ≤ 3 镜）· 镜头语言。

赛车专属八条，逐镜至少落在一条：
1. 前景视差第一法则——灯杆 / 护栏 / 树 / 隧道壁 / 岩壁贴着车掠过。没前景的追逐 = 快不起来的追逐；选窄路 / 林道 / 城市巷道就是这个原因。
2. 贴地——机位越低，路面流速越夸张。
3. 超广角朝前 / 朝后——迎面 / 远去物体涨大与缩小被夸张（Z 轴）。
4. 车身压缩与弹跳——过弯侧倾、悬挂压缩、颠簸回弹；车身是有悬挂的动物。
5. 轮胎与地面——胎烟、水雾、砂石抛洒、刹车锁死的拖印。
6. 热浪扭曲——排气口上方空气扭动（怠速 / 起步瞬间的速度暗示）。
7. 明暗 flicker——车与车手穿过光斑与阴影，一闪一闪。
8. 引擎震动——车载机位的画面必须震（微晃 + 高频抖）；稳定平滑 = 假。

## 四 · 节奏（切点即换挡——赛车版的铁律 1）

- 切点落位三选一：入弯瞬间 / 升挡瞬间 / 反超互换（proximity exchange）的瞬间。三个都是「动作前半段」，切本身就是动作。
- 因果型镜对的切点落在「因刚启动那一瞬」：赛车戏最高频的镜对就是打方向盘 → 车转弯。写「因」的那一镜（手部打方向 / 拉手刹 / 踩油门）时，切点必须落在因 `starts` 的瞬间，下一镜的「果」在同一瞬间起步（`the car answers the wheel instantly`）。不许等因的镜播完才切——模型会把打方向演完再切，观感立刻拖沓。措辞写 `starts`，绝不写 `finishes`。
- 密度：对抗段（轮对轮、攻防、逼抢）照铁律 3 ≥ 8 拍/秒不打折；纯疾走段（直线极速 / 飞坡）按长镜头纯位移段标准：动作锚点 ≥ 2 拍/秒 + 相邻锚点间隔 ≤ 1.000s + 运镜节拍 ≥ 5 类。
- 配比：连续跟拍 ≤ 3 镜，之后必给一镜静机穿越或反向掠过（速度要参照物）；高空地理镜一镜即收；apex 机位与贴车组交替。
- 声音分层：引擎（转速爬升与断油）、换挡咔哒、胎噪（抓地 / 尖叫）、风噪、对手机械声各占一层；升挡声落切点。音效不进配乐层（默认无音乐照旧）。
- 升格的用法：叙事段落间的舒缓（冲线后、回忆插叙）可以；赛段内只许铁律 2 三节点——撞车瞬间 / 千钧一发的反超 / 完美防守走线。

## 五 · 题材红线（自查词表 + 判据）

1. 游戏追尾视角 = 铁律 12 在本题材的头号死法：吊在车尾后上方、与车同向同速、焊死跟随——禁。追拍必须是有自己电影逻辑的独立机位（追拍车并跑 / 直升机 / 静机 / FPV 有理由的穿越）。
2. FPV 穿越也要有锚点：穿哪儿、为什么穿、出去之后到哪——三维锚点条款照用（镜头飞出去必须回到这条赛道：弯道编号 / 护栏 / 路碑 / 桥当锚点清单）。
3. 铁律 2：升格只落三节点；变速声明（倍速）走 `the choreography runs at N times natural fight speed` 的机制，真速优先、提速只许「一点点」且按速度基线规则。
4. 铁律 13：零效果线；速度只走第三节的语汇。
5. 铁律 7：车由参考图定义——外观 / 涂装 / 轮毂一个字不写；内饰与部件特写（挡杆 / 转速表 / 脚）算道具锚点例外，可写几何与动作；车手脸照人脸规则。
6. 车内对话镜：中柱特写传统（拆上半截、4 尺拍脸）——机位要写「为什么在这里」。
7. 撞车与伤亡：铁律 8 照旧，谁撞谁废由用户定。
8. 手部特写必须掐死第三只手：H3 在方向盘 / 挡杆 / 车内任何局部肢体镜头中会幻觉出额外手 / 手臂 / 身体部位。写到手时必须显式声明
   `exactly two hands, the driver's own, no third hand, no extra arm or body part, no passenger anywhere in frame`
   并同步写明手位排程（一次几只手在盘上、哪只手离开、何时双手同时打方向）。措辞精确到「几只手」「在干什么」，不给模型留填空空间。

## 六 · H3 落法

- 车 = `<Subject N>` citing `<Picture N>`（绑定位置 / 比例 / 轮廓，外观零描述）；赛道 = 环境描述或场景参考图。
- 空间锚：弯道顺序 / 护栏 / 路碑 / 桥 / 隧道列成锚点清单写进结构约束——高速位移的赛道最容易「飘出去没有参照物」。
- 时间码链、硬切、反融合、状态等式句照常；每镜机位写「方位 + 高度 + 为什么是这里」（铁律 12 判据）。
- 声音：第四节分层进 `overall_soundscape`；`non_diegetic_music` 默认 `N/A`。
- 加跑校验：逐镜查第三节语汇至少一条在位；静机穿越 / 反向掠过配比达标；游戏追尾词表 0 命中（否定句放行）。
