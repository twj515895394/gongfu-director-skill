## 一、八条核心思路（每个流派只取一条最可复现的）

### 思路 1 · 「连击因果链」——ufotable / MAPPA 的连击节奏
前一个动作是后一个动作的因。 甲一拳打空 → 乙顺着他自己的前臂滑上去反手拍腕。
每招都有目的、都是上一招的结果，不为好看而动——现代动漫 CG 连击戏的通用底逻辑。
✦ H3 写法：「甲这一拳走空，乙的手顺着他自己的前臂滑回来，拍上甲的手腕——」
✗ 反例：「甲刺出。乙挑腕。」——两拍孤立，因果断了。

### 思路 2 · 「单帧余韵」——动漫 CG 止め的延伸
威力不在击中瞬间，在击中之后。 重击落下 → 不立刻爆 → 单帧静止 → 然后目标塌。
✦ 对应铁律 1（末拍禁令）的反向应用：先停再爆 = "还没完"的合法写法。
✦ 用法：重击切成"击中 → 静止 1 帧 → 威力显现"三拍，给余韵（详见二工具表「静帧 / 止め」）。

### 思路 3 · 「长镜头思维」——John Wick
1.25 秒里塞 2-3 个动作而不切。 跨步近身 → 抓腕 → 拽偏 → 顺势推肩，四拍焊一句。
✦ 对应铁律 3（拍数上不去）的根治：每镜焊拍，不再"一拍一动作"。
✗ 禁忌：写时不许加"然后"——"然后"是切镜的语言。

### 思路 4 · 「中心构图 + 急停」——Mad Max Fury Road
主体始终在画面中心，镜头不横移；每镜至少一次急停（动 → 静止 1-3 帧 → 再动）。
点-反点结构：动-静-动-静。急停是动漫合法语言，不是慢动作（铁律 2 的「极快」基调和它一致）。
✦ H3 写法：`the strike holds for a single frame, then resumes`（单帧静止，不是降速）

### 思路 5 · 「轴心自由变」——ufotable / 鬼灭
镜头与主体的轴心本身在变——不是 360° 平移，是视角从甲的右肩后跳到乙头顶俯拍。
✦ H3 写法：「镜头从甲的右肩后侧扫到乙的头顶俯拍」
✦ 风险：H3 三轴心常做不到，两轴心（甲→乙视线交接）几乎都成立。

### 思路 6 · 「大开大合 / 低张数」——MAPPA 咒术朴性厚 / 链锯人
不画密小幅，画大开大合的少动作。 乙不是"侧身让"——乙整个人往后带一步，一帧跨半步。
✦ 对应铁律 11：低张数 = 每帧的动作必须有分量。手腕抖 = 0。
✗ 写法禁忌：删掉所有"轻轻 / 微 / 略"——只剩"重 / 深 / 整 / 全身"。

### 思路 7 · 「Fantasia 调色 / 残影」——JoJo / Trigger 边缘行者
转折瞬间切换整体调色（暖橙 → 冷蓝），或画面叠 2-3 帧运动残影。
两者都是铁律 2「极快」基调的速度感补丁，不是慢动作。
✦ 限制：调色变化全片 ≤ 2 次；残影单镜最多 2 道（配额见二工具表）。

### 思路 8 · 「环境交互」——现代动漫 CG 的物尽其用
道具当武器，环境当战场。 树干、竹枝、落叶、碎石、衣服——能抓的全是兵器；
蹬树变向、肩撞折竹、扫腿带起尘土，都是同一思路。
✦ 对应铁律 10（F 类）：空着的那只手不光可以拍腕、抓臂，还可以抓身边任何东西。
✦ 写法：「乙不等站稳，顺手抄起地上那把竹扫帚横扫甲的小腿——」

## 二、动漫 CG 的两个工具（H3 能直接写）

> 原为三个工具。集中线已被整条删除（铁律 13），保留删除记录以免被重新加回。

| 工具 | 含义 | H3 写法 | 全片配额 |
|---|---|---|---|
| 静帧 / 止め | 打击瞬间 1-3 帧画面静止 | `the strike holds for a single frame` | ≤ 4 次 |
| ~~集中线~~ | 画面四角的辐射线 | ~~`radial speed lines converging on the impact point`~~ | 禁用 · 0 次 |
| 残影堆叠 | 高速动作时画面叠 2-3 帧运动残影 | `two ghost trails of the swinging arm following the arc` | ≤ 3 镜（单镜 ≤ 2 道） |

✦ 配给教训：残影不许每组重拍都拖——12 组 × 2 道会爆配额 8 倍。
正确写法是在结构约束块里点名配给：只给每镜最快的一组挥击，并写明 `and no other shot carries trails`。

✗ 用错位置的代价：静帧只在铁律 2 慢动作的合法节点（巨大伤害 / 差点击中 / 极限格挡）使用，否则 = 隐性慢动作。

✗ 集中线已整条禁止（铁律 13）：它曾经是「配额 ≤ 2 次」的合法工具，用户看图后一句话判死——「画面中不要出现那种漫画的线条，就是四周的这种线条，太抢眼了」。速度感改由 motion blur + 元素拖尾 + 残影堆叠 + 镜头语言承担，不靠任何贴图式效果线。

## 三、什么不要学（避免踩 H3 模型的雷）

| 来源 | 不取的内容 | 原因 |
|---|---|---|
| 程小东 | 威亚 / 长时间空中停留 | 违反铁律 2 慢动作禁令 |
| 鬼灭/ufotable | 一帧 100 米的超速作图 | 模型崩 |
| 咒术/朴性厚 | 大段台词戏的空间调度 | 用户要打斗不是文戏 |
| JoJo | 定身（Mie）≥ 1 秒 | 等于隐性慢动作 |
| 边缘行者 | 大规模血腥爆头 | 用户说过"不要见血" |
| 鬼泣 / 魔女 | 时停 / 魔女时间 | 违反铁律 2 |
| 只狼 | 单挑 AI 学习机制 | 用户是双人对打 |
| 链锯人 | 规则打破 / 概念删除 | 不属于动作设计范畴 |
