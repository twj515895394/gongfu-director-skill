# 特效质感手册（VFX Quality）

用户定案：「我喜欢那种最终幻想 CG 质感，艾尔登法环的魔法特效，龙之信条的特效。不喜欢国产 3D 动漫的那种劣质特效。」——劣质清单做成必扫禁词表。

适用前提：管的是有明确魔法 / 技能设定的打斗（尤其元素对轰）里特效要写成什么样。它不改「能力不解释、不视觉化」那条——那是管不合理的移动能力（站墙 / 滑行），两者不冲突：
- 有魔法设定 → 特效必须高质感（本手册）
- 不合理的移动能力 → 不解释、不视觉化（铁律 7）

## 零、参考作品只在内化阶段用，稿子里一个字都不许提

规则（与铁律 7 同源逻辑——模型会试图整体复刻那部片）：

- 作品名不允许出现在稿子里（分镜与 H3 提示词都不许），包括但不限于动漫、电影、游戏名。
- 稿子里要写的是具体物理描述，不是作品名：

| ❌ 不许写 | ✅ 要写 |
|---|---|
| 「凡人修仙传式雷遁」 | 「电流在空气里扰动，每道电弧的分叉、减弱都符合电磁学原理」 |
| 「灵笼式毛发」 | 「毛发根根独立渲染，风力作用下呈现动态物理反馈」 |
| 「剑来式环境互动」 | 「每一次挥拳都会对周围环境产生扰动」 |
| 「最终幻想那种质感」 | 「粒子本身就是光源，每一击都照亮环境；火焰是流体，有冲击波与碎裂细节」 |

这三部国漫的提炼写法（内部研究材料，用来提炼写法，片名不许进稿）：

| 参考来源 | 提炼出的写法 |
|---------|------------|
| 灵笼 | 毛发根根独立渲染，风力作用下呈现动态物理反馈；疼痛感具象化（皮肤皲裂时皮下肌肉纤维的撕裂、骨刺穿透肢体时血液喷溅的抛物线）；超视距俯瞰战场的广角镜头；中式武术 + 科幻特效融合 |

| 剑来 | 环境互动：每一次挥拳都对周围环境产生扰动；剑气水墨风美学；快慢节奏交替，还原高手过招间的生死毫厘；压迫感与留白的交互 |

## 一、唯一的分界线：特效是不是物理存在

三源风格完全不同，但高质感的根只有一个：特效是画面里真实存在的东西，不是贴在画面上的图形。

| 它在画面里有没有…… | 高质感（三源） | 劣质（国产 3D 动漫） |
|---|---|---|
| 光 | 粒子本身就是光源，每一击都照亮环境 | 光柱是贴上去的，不照亮任何东西 |
| 体积 | 体积雾、体积烟、GI 全局光照、间接光 / 反弹光 | 没有体积，是平面叠层 |
| 材质 | PBR，光在布料 / 金属 / 玻璃上真实反射 | 塑料质感，没有反射模型 |
| 形态 | 火焰是流体、爆炸有冲击波扩散、碎裂有细节 | 火焰是一道 PS 渐变，没有流体、没有冲击波 |
| 交互 | 火蔓延沿地面、冰柱可踩、暴雪在狭小空间更强 | 特效与环境零交互 |
| 魔法 | 是具象的实体（召唤物的爪 / 嘴、身体部位具现） | 是抽象光球 / 光柱 |

> 判断法（一句话）：把这一帧的特效单独拿出来问「它会不会照亮旁边的墙、会不会把地上的水映亮、会不会在玻璃上有倒影」——会 = 高质感；不会 = 劣质。

## 二、高质感三源 · 各自怎么学（2008 线内）

### 1. 最终幻想 CG（FF7 Remake 2020 · FF16 2023）

- 粒子 = 光源：写「粒子落地处把地面映亮」「每一次挥击的火星都在照亮四周」
- 体积雾 / 体积烟：爆炸后的烟是有厚度、能藏住人的体积烟，不是一层灰
- 间接光：主光之外，写出被弹射光 / 反弹光照到的暗部
- 材质反射：光在布料的褶皱、金属的棱线、玻璃上的真实反射（PBR）

### 2. 艾尔登法环（2022）

- 魔法是"信仰的表达"：神秘、符号化、有象征意义的颜色与形态（金色秩序符文 / 黑色火焰 / 龙雷）
- 魔法是"具象的实体"：召唤龙的爪 / 龙的嘴、身体部位具现出来，不是抽象光球
- 颜色有象征：黑色火焰（神皮）、金色（黄金律法）、黄焰（癫火）——给元素一个"身份"，不是随便一个颜色

### 3. 龙之信条（2024）

- 重量感来自读条 + 大范围爆发：越重的魔法，读条越长、环境越被搅动，然后大范围爆开
- 环境交互是重点：火焰沿地面蔓延、冰柱可被踩上、暴雪在狭小空间更强——特效必须"落进环境里"

## 三、正面写法清单（写 prompt 时逐条对照）

1. 粒子是光源：每一粒火星 / 魔法光都在照亮四周，写它照亮了什么
2. 体积雾 / 体积烟：烟与雾是有厚度、能藏人的，不是一层灰
3. GI / 间接光：主光之外，写出反弹光 / 弹射光照到的暗部
4. 材质反射：光在布料 / 金属 / 玻璃上的真实反射
5. 火焰是流体：有流动、有冲击波扩散、碎裂有细节，不是一道渐变
6. 魔法是具象实体：召唤物有形体、有材质，不是抽象光球
7. 魔法有"身份"：元素给一个有象征意义的颜色 / 形态，不是随便一个颜色
8. 特效与环境交互：火沿地蔓延、冰可踩、特效会被环境挡住 / 反弹

> 反面一句话：上面 8 条每一条的反面就是劣质特效的样子。

## 四、国产 3D 劣质特效负面清单（7 条病灶 + 根因）

1. 塑料感——建模 / 铠甲像塑料贴片，没有反射模型
2. PS 渐变火焰——没有流体、没有冲击波、没有碎裂细节
3. 过曝光柱——天降金光柱，贴图、不照亮环境
4. 满屏马赛克色块——高饱和、对比度拉满、没有层次
5. 预设粒子库替代定制——一眼重复的飘带粒子
6. 省略起势与收势——只有"出招"和"结果"（与铁律 11「挥满三段」同一道防线）
7. 慢镜头填充时长——注水（与铁律 2「严禁慢动作」同一道防线）

根因：国产 3D 动漫常用做游戏的方式做动画——捏一次脸、模型互动、套预设素材、不打磨，所以动作提线木偶感、僵硬；特效为了控制成本用模板化素材稀释，于是火焰像 PS 渐变、铠甲像塑料贴片。

### 廉价观感对照表（并入自 3DCG 源技能 vfx-design，2026-10-21）

可核查的表现与修订方向，不是所有失败的预设成因。没有视频时称风险检查；有视频先报实际观察到的镜头和时刻。

| 可见问题 | 优先修改什么 |
|---|---|
| 风像丝带或透明管、烟像棉球 | 明确可见介质、流场方向、主卷动与边缘撕散，补障碍物/厚薄的证据 |
| 石、玻璃、木头都变成同尺寸飞块 | 依材质和支撑确定裂解方式，先局部失效再传播，写出断面与未破坏部分 |
| 有喷射却没有重量或世界反应 | 核尺度、动量路径、接触与反作用；若设定禁止机械反作用，用适用的光学/遮挡证据 |
| 持续沸腾抖动、每帧纹理洗牌 | 让形状沿既有流动演化，微细变化服从主运动；颗粒/裂缝/涡团保留局部时间身份 |
| 切镜后一切复原或重新爆一次 | 保存供给状态、波前/碎片位置、烟尘阶段、损伤和受光，按真实时间推进 |

原表另有三行与上方病灶语义重复已删行：均匀亮片粒子 → 病灶 5 · 霓虹光柱不照亮环境 → 病灶 3 · 全屏发白无层次 → 病灶 4。

## 五、禁词表（必扫，每次生成都跑）

扫法同铁律 13 / 铁律 7：命中即报错，否定句里的命中放行（如「没有塑料感」「不要光柱」不算违规）。

| 类别 | 中文禁词 |
|---|---|
| 塑料感 | 塑料感 · 塑料贴片 · 塑料 |
| PS 渐变 | 渐变火焰 · PS 渐变 · 廉价渐变 |
| 过曝光柱 | 过曝光柱 · 冲天光柱 · 金光柱 · 天降光柱 |
| 马赛克色块 | 马赛克 · 色块堆满 · 满屏色块 |
| 预设粒子 | 预设粒子库 · 粒子库 · 五毛特效 · 劣质特效 · 廉价特效 |
| 过曝 / 光污染 | 过曝 · 光污染 |

> 「塑料」与「光柱」容易误报——塑料只在否定语境放行；合法的光束（如阳光斜照、低角度掠光）不算「冲天光柱 / 金光柱」，要连「过曝 / 天降 / 不照亮环境」一起看，别矫枉过正。

## 六、与现有规则的关系

- 铁律 13（禁漫画式效果线）：仍是整条归零，本手册不放开——漫画线是"贴在图上的图形"，与"有物理感的特效"是两回事。速度线照样禁，粒子特效照样要高质感。
- 铁律 7（能力不解释、不视觉化）：不动。那是管"凭什么能站墙 / 滑行"这类没设定的移动能力；本手册管有明确设定的魔法特效。一条管"没设定就不解释"，一条管"有设定就写到位"。
- 铁律 11 / 铁律 2：劣质清单第 6 / 7 条本来就是这两条铁律在防，本手册把"劣质特效"和它们挂上钩——三道防线是同一道。
- 元素对轰：本手册就是为元素对轰立的标准——有魔法的打斗，特效按本手册写。
