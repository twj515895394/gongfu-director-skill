## 一、母题：谁都没吃到一击

全程势均力敌、招招半空对撞：

- 两人从头到尾不用身体碰对方，一击都不落到人身上。
- 每一次攻击都在半空被对方的攻击截住——两条元素在同一个点上同时撞、同时炸。
- 每次对撞都是互相的 → 谁都没占到便宜、谁都没吃到过一击。

母题三句绝对话（落成全片可扫词表，命中必须全在否定句里，校验法同空手 21 ②）：

1. 全片没有一个技能落到人身上
2. N 次对撞，一次都没漏（没有一发打空、没有一发没人接）
3. 谁都没占到过便宜、谁都没吃到过一击

## 二、铁律对照：哪些沿用、哪些换掉

| 铁律 | 元素对轰怎么改 |
|---|---|
| 1 切在动作中间 | 原样沿用——出手 / 飞行 / 炸开的任一拍切走，末拍只写进行态 |
| 2 慢动作 | 原样沿用（两种合法型都可用）；只留大面积对撞的单帧静止 |
| 3 密度 ≥ 8 拍/秒 · 镜数 ≥ 秒数 | 原样沿用 |
| 4 距离 | 作废「≤ 一臂」：天然远程。改为「周旋 + 远距离 + 空中战」——两人距离 50 米以上，全片不得近身；允许飞行、空中技能、空中打斗；移速可以极快。绕着对方走、侧移换角度、拉开又压近，一秒不许停；所有技能都是远程飞行物，在两人之间的空处对撞。授权的高速位移写成「雷移 / 瞬移 / 飞行」，但贴身近身打击属于用户点名的例外，默认不写 |
| 5 反应先于命中 | 改为「反应先于出手」：读的是对方的起势，回敬的技能在对方技能飞过半程前就已经出手 |
| 6 手持 + 景别 + 全景配额 | 沿用，全景仍只给大面积对撞 |
| 7 参考图：脸只取最左、外形不写 | 原样沿用 |
| 8 中了就出血 | 改为「零伤」：没有人被击中，伤情表按 0 报。代价改写两处——① 场地（炸出的坑 / 犁出的焦痕 / 掀掉的墙角）② 自身后坐（被自己的技能推得退半步） |
| 9 硬切 | 原样沿用（「硬切」指切与切之间，镜内运镜已放开，见 `camera-language.md`） |
| 10 化解不许连用同类 | 改为「撞法不许连用同类」：见四 |
| 11 每击挥满弧线 | 改为「每发技能走完三段」：起势（凝）→ 挥满（离手 / 飞满）→ 过身（炸开即接下一发起势） |
| 12 电影机位严禁游戏视角 | 本打法风险最高：对轰天生滑向「横版街霸」——两人并排站同一水平线互相出招。机位必须逐镜重选，可用：长焦横移跟飞行物 · 贴技能飞行轴往后拉 · 仰拍落雷 · 随爆点上下颠 · 镜头被冲击掀得后仰 · 反打 · 肩后 · 前引倒着退 · 长焦压缩。纯侧向 ≤ 1 成 |
| 13 禁漫画式效果线 | 本打法第二个高风险点：技能对撞天然诱发「径向效果线从四角闪向撞击点」。速度感改由 motion blur + 元素拖尾 + 残影堆叠 + 镜头语言承担 |

## 三、技能谱系：给双方一张招式表（各三档，可选一种近身）

不要写「放技能」，要写形态 + 尺度 + 尾迹。 参考粒度（15s 片给 5~7 档就够）：

| 系 | 平A | 中档 | 大招 | 可选近身 |
|---|---|---|---|---|
| 火 | 指弹火丸：拳大、连发、短尾焰 | 大火球：人头大、长尾焰、炸成半球 | 熔岩陨石：上方落下、砸出坑 | — |
| 雷 | 雷针点射：细长、打中炸一小团 | 雷电粒子冲击波：整排推进、一次扫掉一排 | 天雷：天降雷柱、可连续多拍 | 雷拳：雷移贴身 + 手上聚雷砸出 |

技能形态硬约束：

- 禁止动物模样——火龙卷、凤凰、雷蛇、雷龙、火鸟、雷兽等一律不许。
- 必须是魔法师式：法阵、符文、魔法阵、元素凝聚、元素射线、元素屏障。
- 写法：`a magical circle condenses around his feet`、`runes glow on the ground`、
  `a fire rune launches from the magical circle`
- 召唤线（法天相地 / 万剑）见 `magic-summoning.md`，那条线同样禁动物形态。

密度靠对撞，不靠技能种类——15s 片 21 次对撞用 6 档技能撑得住。

## 四、对撞点模型（本打法的核心机制）

1. 一拍只设一个对撞点，从不并列两处（＝空手「一拍一处接触点」）。
2. 对撞点必须落在两人之间的空处或两人上方——不许落在人身上。
   两人距离 50 米以上，对撞点在中点，离两人各 25 米以上。
3. 七种撞法，相邻两镜不许用同一种（同一镜里连着两次同撞法是节奏，放行——如「三连正消」是一串，不是重复）。15s 片建议 6 种全用到：

| 撞法 | 长什么样 |
|---|---|
| 正消 | 两股正中撞上、互相抵消、炸成一团 |
| 横切 | 横向推进的那股把纵向下来的从中间切断 |
| 偏折 | 斜擦着撞上，把对方那股带偏出原本的路线 |
| 贯顶 | 从上方砸下来的那股把下面那股直接砸散 |
| 裹住 | 一方的元素把另一方的整个裹进去、一起炸开 |
| 对顶 | 两边势均力敌、顶在同一个点上一齐往死里推，谁都不退 → 大面积对撞专用 |

4. 大面积对撞：整屏吞没 3 帧（其余对撞只 2 帧）+ 甩一圈冲出画面四边的元素冲击环 + 单帧静止。15s 片给 3 次。
5. 大面积对撞 = 全片唯一允许的全景（配合铁律 6 的放宽）：别处一概不给全景。
6. 每个对撞拍都要在正文里点名撞法——汇总段（「正消 → 镜 1 / 6 / 9」）与逐拍正文必须对得上。正文省了撞法，模型就会把 N 次对撞演成 N 次同一个爆炸。

## 五、对轰特有的坑

- 最大坑：法师对轰滑向横版侧视（见二·铁律 12 那一行，机位清单在那里）。
- 第二坑：距离太近变贴身。元素对轰是远程对轰，两人距离必须 50 米以上，全片不得近身；写「两人隔着 50 米以上的空场对轰」，不写「两人贴身对轰」。
- 第三坑：把法师钉在地上。允许飞行、空中技能、空中打斗，移速可以极快；写「两人在空中高速移动、技能在飞行中出手」，不写「两人站在地上对轰」。
- `站定` / `停住` 是禁词——即使语义是「周旋」也不能写「两人站定对轰」（模型会演成静止）。写「一直在周旋，一秒都没停」。
- 高空落雷 / 陨石很容易被拍成俯视战场（战术视角禁项）——俯拍本身合法，但必须是为这一镜的接点选的俯冲机位，不是「看整个战场」。
- 别拿「对撞」当挡箭牌省掉密度：位移 / 凝气的镜照样 8 拍/秒。
- 零伤不等于没代价：场地的坑 / 焦痕 / 塌墙 + 各自的后坐，是这一打法唯一的力量表现通道。

## 六、对轰加查（在 21 项之外）

1. 对撞拍数 = 声明数；无同拍并列；按时间递增
2. 每个对撞拍正文点名撞法；相邻两镜撞法不同；对顶（僵持）≤ 1/3
3. 大面积对撞 = 声明数（15s 片 3 次）；全景镜 == 大面积对撞镜（多一次即违规）
4. 距离检查：全片任何时刻两人距离 50 米以上；对撞点在中点，离两人各 25 米以上；无贴身近身打击（除非用户点名）
5. 空中战检查：允许飞行、空中技能、空中打斗；移速可以极快；无站桩地面战
6. 母题三句绝对话落成词表全片扫，命中全在否定句
7. 零伤声明 + 代价写在场地与后坐上（不是写在人身上）
8. 每发技能三段齐全（凝 / 离手 / 炸开）
9. 技能形态检查：禁止动物模样；必须是法阵 / 符文 / 魔法阵 / 元素凝聚
10. 机位词表 0 命中（否定句放行）+ 纯侧向 ≤ 1 成 + 逐镜机位互不相同
11. 漫画式效果线 0 命中（铁律 13）——对轰是这种线条的重灾区

通用加查在各自文件：镜头语言 ≥ 3 种 · 动作蒙太奇 · 空间转换 · 人物物理 → `camera-language.md`；特效质感与劣质特效禁词 → `vfx-quality.md`。

## 七、结构骨架（只给量级，不给旧片数字）

> 用户已删除全部历史稿，并要求以后每片都是全新创意。 本节不保留任何一版的具体时间码 / 撞法配比 / 技能数目——那些正是复刻源。下面是量级区间，每一片都要重新填。

| 项 | 合理量级（15s 片） | 要求 |
|---|---|---|
| 镜数 | 15 镜起（镜数 ≥ 片长秒数） | 逐镜重选机位 |
| 拍数 | 片长 × 8 | 落 0.125s 整格 |
| 对撞拍 | 18～24 次 | 时间码必须重新选，不许沿用任何旧片 |
| 大面积对撞 / 全景 | 3 次（或用户指定数） | 两稿声明的次数必须一致 |
| 技能档位 | 每方 3 档 + 可选 1 近身 | 招式族整族重选，不是在旧清单里换顺序 |
| 切点节奏 | 形状随内容定（等分 / 加重 / 呼吸…） | 形状本身就要换，不是把旧序列改两个数 |

H3 侧标记（格式约定，可长期沿用）：每个对撞拍句内带 `a clash on that point`；大面积对撞再加 `a large burst`；撞法用 `head-on cancellation` / `lateral cut` / `deflection` / `overhead break` / `engulfing` / `deadlock`；母题声明句 `neither man ever touches the other with his body`。
