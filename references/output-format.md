## 交付模式与产物分级

默认使用**标准模式**。用户明确要求精简/完整审计时按其要求执行；任务探索阶段可用精简模式，最终验收或复杂场景可升级完整审计。

| 模式 | 核心产物 | 默认报告内容 |
|---|---|---|
| 精简 | 中文分镜稿 + 与目标模型匹配的完整可用提示词 | 关键问题、主要修改点与必要风险；不输出重复的全量审计表 |
| 标准（默认） | 中文分镜稿 + 完整生成提示词（常规模型默认中英双版；H3 为纯英文六段式 `.txt`） | 逐镜速览、总时长/字符数（注明统计口径）、基础/专项校验结论、失败项与风险 |
| 完整审计 | 标准产物 + 本任务适用的详细校验报告 | 按 `full-audit-checklist.md` 和 `action-timing.md` 输出适用的密度、动作分布、伤情、连续性、版本差异等证据；不适用的项目不强行填表 |

### 俯视调度图 PNG 的交付条件

- **必交**：用户明确要求；多人走位或复杂攻防；明显的大幅位移/飞行/三维运动；长镜头；多场景切换；轴线、机位或银幕方向存在较高风险。
- **默认可省略**：简单对话、静态场景或低位移场景，且用户未要求图示。此时中文分镜稿仍须写明轴线、角色位置/朝向、机位侧与关键走位，并逐镜完成空间连续性检查。
- 不生成 PNG 不等于不做空间设计。任何模式都不能省略用户点名的镜头、空间约束或必要的动作信息。

### 校验报告与正文分离

完整提示词文件必须自洽、完整、可直接粘贴；聊天正文不重复粘贴整份提示词和所有审计细节。标准模式只展示关键结论、失败项和风险；只有用户要求全量审计或任务触发完整审计时才输出适用的详细表格。精简的是报告展示，不是必要检查。

## 完整模板

```
【参考图说明】

图1：人物A，<一句话形象描述，供 AI 对齐参考图>

图2：人物B，<一句话形象描述>

图3：场景，<一句话环境描述>

（图N 数量与用户提供的一致，不增不减）

【质感词语】<真人实拍感/3DCG/手绘动画>，<色调>，<光影>，<画幅>

【声音设计】<配乐风格与情绪 / 纯音效>，<对白：有/无>

【场景一 · 轴线声明】主轴线：<两角色视线连线/运动方向>；机位区：轴线<X侧>；调度：<各角色起始位置与走位>

镜头1：<景别>，<拍摄方位·拍摄高度>，图1的A<与图2的B>在图3的场景里<动作+情绪>，<画面位置>，<运镜>，<时长>

镜头2：……

【场景二 · 轴线声明】……

镜头n：……
```

## 填写示例（双人对话，6 镜）

```
【参考图说明】

图1：人物A，穿灰色西装的中年男人

图2：人物B，扎马尾的年轻女人

图3：场景，深夜的天台，远处城市霓虹

【质感词语】真人实拍感，冷蓝色调，霓虹逆光，16:9

【声音设计】纯音效（风声、远处车流），无配乐；有对白

【场景一 · 轴线声明】主轴线：A与B的视线连线；机位区：轴线东侧；调度：A倚栏杆面北，B从楼梯口走入停在A右侧两步处

镜头1：大远景，A左后斜侧·平拍，图1的A独自在图3的天台栏杆边抽烟，A在画面右三分点、面朝画左留白，城市霓虹占画面下半部，固定，6秒

镜头2：全景，B右前斜侧·平拍，图2的B走入图3的天台，停在A右侧两步，B自画右入画，移，5秒

镜头3：中近景过肩，过A肩拍B正面·平拍，从图1的A肩后看图2的B说话，B居中、A的肩背占画左前景，固定，6秒。B对白：「你果然在这。」

镜头4：中近景过肩，过B肩拍A正面偏侧·平拍，从图2的B肩后看图1的A，A居中不回头，固定，5秒。A对白：「风大，回去吧。」

镜头5：特写，B左前45°·平拍微俯，图2的B（调用图2面部特写视角）眼眶发红，B面部居中，缓推，4秒

镜头6：大远景，两人正侧方·平拍，图1的A与图2的B并肩在图3的天台栏杆边，A画左、B画右，霓虹渐暗，缓拉，8秒
```

## 字段规则

- **排版硬规则**：每条「图N」、每条「镜头N」都**独立成行且前后空行**（Markdown 下连续行会被并成一段，排版全毁）；【参考图说明】【质感词语】【声音设计】【场景N · 轴线声明】各为独立小节，与正文之间空行分隔。写 .md 文件时节标题用 `##`，对话里直出时保持空行即可。
- **景别**：中文（大远景/远景/全景/中景/中近景/近景/特写/大特写/过肩），用户要求缩写时用 ELS/LS/FS/MS/MCU/CU/ECU/OTS。
- **机位四要素（每镜必写，缺一项即返工）**：拍摄方位（正面 / 斜侧 45° 写明左右 / 正侧写明左右 / 背面 / 过肩）、拍摄高度（平拍 / 俯拍 / 仰拍 / 顶拍 / 贴地）、运镜（固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 手持）、画面位置（画左 / 画右 / 居中 / 三分点；双人写相对位置；视线与运动方向前留白）。方位与画面位置从俯视调度图推算翻译，词汇表见 `camera-language.md` 附录 D。**画左/画右不许凭直觉**：取相机指向目标的向量 (dx,dy)，画面右方 = (dy, −dx)；角色的朝向向量与画面右方做点积，正 = 面朝画右，负 = 面朝画左；相邻两镜同一角色的朝向画侧必须连续，切镜前后写状态等式衔接（如「手还揪在衣领上」）。
- **参考图编号**：每镜至少引用一个「图N」；角色出场引人物图，环境描述引场景图。
- **动作描述**：一句话写清「谁 + 在哪 + 做什么 + 什么情绪」，不写模棱两可的文学修辞。
- **对白**：挂在对应镜头末尾，格式「X对白：「……」」。
- **编号**：镜头 1 到 n 连续编号，跨场景不重置。
- **轴线声明**：每场必写，放在该场镜头列表之前；若角色走位改变了轴线，写明新轴线与新机位区。

## 中英文双版提示词（默认配套，中文版审阅 · 英文版生成）

每次出提示词默认交一套两版，用途不同，不许合一：

- **中文版** = 上面「完整模板」的中文分镜表：给用户逐镜检查提示词内容、判断哪里要优化修改。
- **英文版** = 直接粘给生成模型的提示词本体：**默认必出**，不待用户点名 H3。点名了目标模型就按该模型的格式习惯出（H3 → 六段式 `.txt`，见下节）；没点名时按中文分镜表的段落结构逐段英文化——质感总纲 + 参考图声明 + 每镜一段（`Shot N` ↔ 镜头 N），整份「全选 → 复制 → 直接粘」。
- **两版一致是硬线**：信息级对齐——动作顺序、数值、朝向、图号、材质光影、声音设计逐镜对得上；中文版不许有英文版没有的内容，英文版也不许多出或丢失信息。英文默认块（`look-quality.md` 底块、防误判三件套等）只存在于英文版，中文版以【质感词语】【声音设计】等中文段落对应。
- **改稿同步**：用户改中文版 → 逐处同步进英文版 → 交付前按镜号复查两版对齐；只改一版就交付 = 违规。
- 用户显式点名只要中文版或只要英文版时，照点名单发。

## H3 输出规则

当用户说明目标模型是 H3 / MiniMax H3 时，英文版即采用官方六段式直出（官方格式子技能 `h3-prompt-writing` 在 `minimax-h3-skill-router/skills/` 下，可作格式对照，冲突以 `storyboard-structure.md` 为准），中文分镜表照常附带（双版制下的审阅版）：

- 多图参考（人物图+场景图）走 Ref2VA 六段式：`subject_definitions` / `summary` / `retention_analysis` / `detailed_description` / `overall_soundscape` / `non_diegetic_music`，字段名与顺序不得改动。
- 参考标签全稿一致：人物/场景定义为 `<Subject N>` 并注明来源 `<Picture N>`；四视角图在 subject 定义里写明「面部特写用左一大特写视角」。
- 时间轴与分镜表一致：`[Shot 1]` 无时间戳，之后 `[Shot N] At MM:SS.mmm`，总时长匹配用户要求。
- 对白保留原文放入 `<d>[语言] …</d>`；无对白则不设 speaker。
- 质感总纲用 references/look-quality.md 的英文底块打底（3DCG 时），放在 `detailed_description` 开头、[Shot 1] 之前。
- 不要自己发明六段式之外的「英文翻译版」。

## 提示词的确定性规则（防止模型自由发挥）

1. **机位与朝向必须写死**：每镜从该场景的轴线声明/俯视调度图翻译出摄影机方位与观众视角——「从 A 的右后方拍摄，画面里是 A 的右后侧背影」「我们看到 B 的左脸」。只写「面朝轨道」这类无参照系描述是事故源（模型会在面对镜头/背对镜头之间随机发挥）。角色不该转向镜头时明写 `she does not turn toward the camera at any point`。
2. **复杂动作：动作名放句首 + 结果先行 + 签名动作不可省**：先报动作全称（`executes a fast over-the-shoulder judo throw`），再给结果（B 头朝下翻过肩膀、背部平拍落地），发力链压缩跟在最后。签名动作（过肩摔的 `head-over-heels over the shoulder`）必须点名——只写「弧线/甩向某侧」模型会简化成横推。长句里关键动词别埋在中段。
