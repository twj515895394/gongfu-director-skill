## 铁律 1 · 每一击都切在动作中间

切点落在动作前半段——切走时招还在走，下一镜接这半下没走完的动作。

- 末拍只写进行态（还在 / 已经 / 才 / 半路）。终态词「撞上 / 接住 / 锁死 / 站回 / 稳住」是「做完还停半秒」的唯一根源；撞击一次都不许落末拍——落镜中段，或留给下一镜前两拍。
- 删掉所有收势句：`镜头结束时` 一律改成 `交接给下一镜` 的进行态；禁「站定 / 停稳 / 两个人都还站着」。
- 镜内分号流：`他一拳打出；这一拳还没走完，对方的前臂已经在转——` 用 `;` + `and`/`while` 把拍焊死。每镜句号/分号比 ≤ 1.0。
- 压停顿用否定句：`without a break in it`、`nothing has come to rest`。
- 静镜只静镜头：人必须一直在动，且在动作已起步、还没落地时切走。
- 因果型镜对：切点落在「因」刚启动的一瞬（`the cut lands the instant the wheel starts turning`），下一镜的「果」同一瞬间起步；措辞写 `starts` 不写 `finishes`。
- 核法见 `action-timing.md` 五。

## 铁律 2 · 严禁慢动作（快慢镜 = 唯一合法形态）

力度靠快切 + 密度 + 时长精确，不靠慢动作。只有三个节点可以慢：① 巨大攻击伤害 ② 差点极限打到人 ③ 完美防御住了。合法形态是镜内 `speed ramp`（不切；切到慢素材 = 剪辑断点），四选一：

| 型 | 形态 | 用在哪 |
|---|---|---|
| ramp-in-hold（标准） | 正常速 → 降 → 保持 → 升回 | 撞击 / 命中 / 极限闪避 |
| ramp-in-only | 正常速 → 降 → 保持到镜末 | 段落落点就是那一下 |
| reverse ramp | 慢速起步 → 加速炸回正常速 | 从静止 / 僵持里突然发力 |
| extreme ramp | 降到 1% 以下，近似冻结一帧 | 只给最重的那一下 |

- 两种都收：① 命中慢 ② 蓄力慢 → 命中提速；慢必须服务于那一击，不许慢完再等。
- 默认全片 0 次；一镜最多一次、不连续两镜都用；不许为了好看而加。豁免：用户当轮点名「整段慢动作 / 整镜升格」时按显式风格点名执行——仍须逐个报出归类、变速落 0.125s 帧格对表，且只覆盖被点名的段落。
- 落在帧上不落整镜：`11.600s 起 0.150s 内降到 0.40 倍速`——整镜慢放必掉帧抖动。走曲线（ramp in/out）不许硬跳变；变速段 motion blur 连续；每个 ramp 都要有理由。
- 隐性慢动作同样禁：长静止、缓慢推近/环绕、「气氛凝固」。
- 交付时逐个报出并归类，归不上类的直接删。不交手段（纯位移/滑行/坠落）整条不用——没有碰撞就没有慢的理由。
- 速度感靠镜头速度语汇（`long-take-directing.md` 五·1 · `heavy-impact-playbook.md` 六）。

**非打斗戏的速度规则**（文戏/抒情/日常）：默认真实物理速度，严禁 AI 式无故飘慢。**倍速以正常速度为基准**：用户说「N 倍速」动作本身按该倍速完成（不是后期拉速度）——发力链不变、节奏整体压缩，镜头时长同步缩短重算。快到帧间读不清时**先问用户**：动态模糊还是模糊闪现（smear frames），不擅自决定。

## 铁律 3 · 打斗密度 ≥ 每秒 8 拍

「一个回合」= 甲攻 → 乙应对 = 2 拍。8 拍/秒 = 每拍 0.125s（3 帧）。

- 重拍组 = 一次挥满整条弧线，占 3 拍（起势 → 挥满 → 过身，三拍全归同一人）；对方化解占紧邻 1 拍（预动写进「挥满」格的「已经…」里，保证反应先于命中）。
- 重镜每镜 2 组、快镜每镜 1 组；收势即下一次起势，弧尾不许停。
- 总拍数 = 片长 × 8；拍点全在 0.125s 整格上，每镜首拍 = 该镜起始时刻。按整秒跑滑动窗口核，总平均会骗人；改镜数后逐镜拍数必须脚本重数。
- 拍数上不去是结构问题：① 攻守写同一句 ② 连接句焊拍 ③ 一镜装 5 回合。
- 镜数下限 = 片长秒数：15s → ≥15 镜。先定镜数再塞拍——镜数不够把长镜切碎（一镜 1 组挥满 ≈ 1.0–1.5s），不是每镜加回合。用户未给时长时先问时长再定镜数；任何「5–15 镜」类默认值都不得压低本下限。

**⚠️ 本条只适用于打斗（快剪流）。文戏镜数另有一套，见下。**

## 铁律 3-补 · 文戏镜数：宁少勿碎（2026-09-28 用户定案）

**用户原话：「像这种文戏尽量不要用过于多的镜头来表现，除非是打斗的戏。镜头太碎了影响叙事。」**

打斗靠碎切造密度，**文戏靠长一点的镜头造叙事**——两者方向相反，不许把打斗的镜数逻辑套到文戏上。

| | 打斗（快剪流） | 文戏 |
|---|---|---|
| 镜数 | ≥ 片长秒数（密） | **约每镜 1.5–2.5 秒，15s → 6–10 镜** |
| 单镜时长 | 0.7–1.5s | **1.5–3.5s**（情绪节拍要留呼吸） |
| 切点驱动 | 动作中间（铁律 1） | 情绪/信息转折点，不是动作帧 |
| 台词镜 | — | **一句台词尽量一镜装完**，不为切而切 |

三条执行口径：

1. **合并优先**：一个动作链能在一镜内连续走完的，就不拆。A 挣脱→转身→走开，可以是 1 镜内的连续运动，不必拆成 3 镜。
2. **台词镜不切碎**：一句台词中途切镜会打断语气。台词镜给足时长把话说完整（除非刻意要打断效果）。
3. **反应用长镜**：情绪反应（愣住、咬牙、被钉住）给 1.5–2.5s 让观众读到，不给 0.8s 一闪而过——**切太快观众根本没看清表情，等于白演**。

例外（可以切碎）：① 用户点名要某种快剪观感 ② 有明确的蒙太奇意图（时间跳跃、并列对照）③ 打斗或追逐段。

**行业口径背书（ASL 平均镜头时长）**：本条的「文戏 1.5–2.5s/镜」≈ ASL 2s。行业数据：动作片 ASL 2–4s（《疯狂的麦克斯 4》≈2.7s）· 经典好莱坞 8–12s · **剧情文艺片常 >10s**（《2001 太空漫游》≈13s）。即**行业文戏比本条还慢**，说明本条口径偏保守安全，不需要放宽。详见 `emotion-to-camera.md`。

**情绪镜偏赶的根因不在镜数，在停顿**：情绪戏的节拍 = 动作 + **动作前的停顿**。实测最有张力的不是动作本身，是「开口前停了一下 / 转身前没有立刻走 / 手停在半空」。只给动作不给停顿 = 偏赶，此时应加时长而非加镜数。详见 `emotion-to-camera.md` 规律 2。

**旧账复核**：本条出台前，站台质问 v1（15s 拆 15 镜）即为反面样本——文戏被按打斗密度切碎，用户判定「影响叙事」。
- 数法见 `action-timing.md` 二。

## 铁律 4 · 打斗不是站桩：默认周旋，压制才后退，拉开要顶回

位移是压制关系与节奏的产物；打的是「来回」。

- 默认周旋：两人一直换角度、试探、微调距离——侧移、换步、绕向、探步，脚下一秒不许停。
- 三种状态：周旋（默认）· 压制 → 被压方退 · 拉开重置 → 再压近。退与拉开都要顶回；只拉开不压回 = 驱赶。
- 谁被压制由用户点名；他没说的当轮位移只准「一点点」：一次半步、一镜 ≤ 1~2 步。
- 距离上限放开，三条禁令不废：① 不许跑 ② 不许拍成追逐 ③ 不许无意义走位。
- 授权① · 高速冲刺段（blitz）：他点名「高速移动 / 冲刺」时放一段限定区间冲刺——前后仍是贴身战；分开两拍之内必然撞上（`never run, only charge`）；大位移全片 ≤ 1 次且立刻被顶回。写法见 `heavy-impact-playbook.md` 七。
- 授权② · 完全放开位移：他点名「几百米拉开 / 追回来」时放开「不许跑、不许追」。三个护栏：① 不离开图 3 那片场地；② 每次拉开都不是躲，同一回合内必被追回或自己折返；③ 追与被追角色可交换，但两人始终互相面对。距离感靠三层元素画出来、不靠拍跑步——`heavy-impact-playbook.md` 十一。
- 镜头：有位移写清「随两人横移 / 倒退拍 / 被冲刺甩开再追上」；原地镜写「骑在两人重心上晃，不往外走」。
- 数法见 `action-timing.md` 三。

## 铁律 5 · 反应真实：先于命中 + 微表情

写成「打到了才躲」整场戏立刻变回合制。正确链：`甲启动 → 乙读取意图 → 乙开始动 → 攻击到达 → 乙已经不在那了`。守方写预判（读重心 / 肩膀 / 拳锋启动），不是看到。

- 措辞：`already`、`reads the intent`、`committed to the defence first`；禁止 `and then`、`after being hit`。
- 风格总纲写一句：`defenders react to the initiation of every attack, never to its contact`。
- 滞后可放行只有两种：① 刻意躲不及（写明判断晚了一线）② 受上一击影响而变形（写明是上一击的后果）。

**微表情（全题材通用）**：每个交互动作都要有反应方的真实反应（被抓手→惊讶先看自己的手；被摔→痛苦一闪再转委屈；被冷落→视线躲闪）。用户没写的由你补写；不确定就先联网查同类场面的反应处理。时序：刺激 → 微表情（约 0.3–0.5 秒）→ 动作回应。微表情库见 `action-physics.md`。

## 铁律 5-补 · 动作链完整性：施动方必须走完全程（2026-09-28 用户实测抓出）

**用户原话：「为什么B去伸手抓A衣领的镜头没有了？这个动作都没有了，只有直接已经抓住了，没有之前的动作衔接」**

铁律 5 只管「**反应方**真不真」，管不到「**施动方**的动作过程是否被呈现」。两条合起来才完整。

**硬规则：凡有交互的动作，施动方的动作过程必须可见，按三段写全——起手 → 接触 → 结果。**

| 段 | 写什么 |
| --- | --- |
| **起手** | 肢体从哪里启动、朝哪个方向、什么姿态（`扬臂破空、五指张开`） |
| **接触** | 动作与对方身体/物体相接的那一下（`五指收拢攥住衣领`） |
| **结果** | 接触之后的形变与受力（`立领被攥出褶皱并横向带偏、在拳中落定`） |

**最高频翻车形态**：上一镜还在 A（脚 / 环境 / 前一个状态），下一镜**直接给了结果态**（手已经攥住 / 刀已经插进 / 人已经倒下）。**中间的过程被剪掉了**，观众看到的是凭空出现的状态。

**⚠️ 合并镜头的头号副作用**：做「文戏宁少勿碎」的合并时（铁律 3-补），极易把某个**动作单元**当成「过渡帧」并掉，只留结果态。**合并只许并「同一动作之内的冗余切点」，不许并掉整段动作过程。** 实测事故：站台质问 v1（15 镜）合并为 v2（9 镜）时，「B 伸手抓衣领」被并掉，直到 v5 才补回。

**例外**（可以只给结果态）：① 刻意省略制造悬念或冲击（须写明是有意的：`before the cut the hand is still at B's side`）② 结果态本身是信息点（如开场已经在打的场面）③ 动作发生在画外且有声音交代。

自查：逐个交互动作问三句——「起手在哪一镜？接触在哪一镜？结果在哪一镜？」三问有一问答不上来，就是动作链断了。

## 铁律 6 · 手持 + 景别跟幅度走（交替放开）

- 默认手持：呼吸感微晃，随动作迟滞、受击瞬间被撞一下；晃幅小、有理由，不要稳定器般的平滑。
- 景别由动作幅度决定：重拍组必须用中景（全身 + 脚下的地入画），否则挥满被画框切掉；快拍段近景 / 中近景 / 特写。
- 配比：中景 ≤ 一半，全景 < 两成；他点名「全景只在大爆发时给」→ 全景 = 大爆发专属。景别逐镜不同。
- 他点名的景别一律照办、不受配额约束（硬规则 14）。
- 打斗动作段禁推拉变焦（zoom / dolly push）——本条只管打斗动作镜；文戏情绪镜的慢推 / 缓拉 / 推轨变焦按 `emotion-to-camera.md` 合法，镜内运镜总则见铁律 9。打斗段合法运镜：横移跟拍 · 升降 · 轴心切换 + 四种已验收：跟拍被冲刺甩开再追上 · 静镜纹丝不动拍冲线交错 · 镜头随撞击上抬 · 镜内视角跳换（镜内摇，不是切）。
- 手持环绕是速度语言不是稳定器语言——绝不写 `slowly arcing`（= 铁律 2 隐性慢动作）。总纲写死 `it never sits still, and it never orbits slowly`；环绕半径与高度逐镜不同，必留 1–2 镜不环绕做对比；镜头运动不入音效层。详见 `heavy-impact-playbook.md` 十。
- 逐镜写明手持 / 固定 + 景别；分镜用大白话。

## 铁律 7 · 参考图：脸只取最左，外形一个字不写

四视图横排、位置固定：最左 = 面部特写（一切近景的脸只能从这格取）；左二/左三/最右 = 正面/侧面/背面全身。

- **零外貌描述只约束 H3 英文稿**：长相、发型、服装、身材一个字都不写——只写「以图为准」声明 + 四视图取用规则。模型听文字不听图，零容忍。
- **中文分镜表是人读件**：允许给每个角色一句话形象描述，不进 H3 稿。
- 写「最左侧」，不写「正面面部特写」——位置词比形容词可靠。用词中性化。
- 唯一例外是道具：当轮有兵刃 / 道具，几何锚点照旧写（直身双刃 / 全长中脊等），他说「连这个也不写」才删。
- 不许给人加装备：图里没有的一样都不加。要解释「凭什么做得到」时，正确做法不是加装备，而是不解释。
- 能力不解释、不视觉化：不合理能力（垂直玻璃上滑行等）全片不解释，画面不放任何东西表现——没有光晕、能量场、力线、粒子、符文、涟漪、颜色变化。`他们就是能`。有明确魔法设定的打斗（元素对轰）不适用本条——特效必须写到位（`vfx-quality.md`）。两者同片可并存，别混。
- 自查允许的命中只有三类：① 否定式 ② 渲染质感 ③ 取用指令。英文服装词表自查：`tunic / trouser / sleeve / garment / outfit / attire / hairstyle`。
- 局部肢体镜头显式掐死额外肢体：`exactly two hands, the driver's own, no third hand...` 这类声明；手位排程精确到「几只手」「在干什么」。
- 默认不读参考图：图由用户自己交给 H3，只按编号点名。他当轮明确问形状/材质时才启用 `user-style.md` 的放大读图法。
- 「以图为准」管不到音轨：音色与性别必须文字声明（逐人音色 + 每声带 `(Sx)` 标签 + 禁令三连，`generation-feedback.md` 案例 3）。

## 铁律 8 · 中了就出血，但伤不许一直累加

没有铠甲的地方被砍中 = 破皮 = 出血。不写「只是划破了衣服」把血绕过去。

- 血是「结果」不是「修辞」：写血往哪走；一旦流出就不消失，后续每镜都带着，收尾交代总账。
- 不许单方面挨打：两人伤口数相差 ≤ 1；谁倒下去由用户定，不自己安排 KO。
- 平衡伤情首选复用已有的口子；出血克制：不喷溅、不美化、不给持续血流音。
- 见血 ≠ 可以慢；被打中那下仍要先写守方在读、在躲，躲不开的原因必须写明。
- 当轮说「不要见血」：全部命中被架住/卸掉，伤情表按 0 报。
- 数法见 `action-timing.md` 六。

**⚠️ 脸部受击的红——绝不用否定句写（2026-09-28 实测翻车，案例 18）**

用户当轮说「不要见血 / 不留痕」时，**不许写成 `no redness` / `no mark` / `the cheek takes no redness`**——否定句里点名 `redness`，模型就听到「redness」，反而给你一整片饱和红。

正确做法是三步：
1. **正面锚定「无变化」**：`the skin stays the same cool pale tone as the rest of the face`
2. **把「红」降级成一声呼吸**：`no more than a faintest warm flush, low in saturation, fading out before it reaches the jaw, gone within a heartbeat`（若要更轻：`barely a breath of colour at the very edge of the cheek`）
3. **把冲击力转交给姿态与眼神**（这是关键——红没了，戏不能少）：`the face shows the impact entirely through the turn of the head and the set of the eyes, not through colour on the skin`

三条禁令：① 脸部红禁写 `flushed` / `reddened` / `swollen` / `bruise` / `raw` 单独成句 ② 禁写「红从哪漫到哪」的大范围渐变（= 腮红）③ 与 `look-quality.md` B 支的「cheeks carry no color of their own」不冲突——**那句是常驻底块，本条是这个底块在受击镜的强化重申**，两句要同镜共存，不是互相覆盖。

用户对浓淡的默认口径：**很轻很轻**。除非他当轮点名要更重。

## 铁律 9 · 一律硬切，不许融合

- 唯一允许的转场是硬切，显式禁用：dissolve / fade / cross-fade / wipe / morph / 黑场。
- 只管「切与切之间」，不管「镜内运镜」——镜内推、拉、摇、移、升降、环绕、变焦都合法（`camera-language.md`）。
- 每次切换写出驱动这次切换的匹配逻辑（九种匹配类型见 `action-timing.md` 末节）。
- H3 会把相邻两镜融合——四道防线：① 字面写 `CUT TO:` ② 约束块加防融合条款 ③ 每镜不同景别与机位 ④ 状态等式句（镜末状态 = 下镜起始状态）。
- 真被融合了：减镜数，不要再加约束文字。

## 铁律 10 · 化解不许只用架挡

三条硬指标（取用表见 `action-vocabulary.md`）：

1. 解法不许连用同类——连续两镜的守方化解不许属同一大类（A 头身闪避 / B 位移 / C 地趟翻滚 / D 下盘腿法 / E 空中腾跃 / F 上肢手段）。
2. 格挡占比 ≤ 1/3。
3. 每 8 镜必含：≥2 次纯闪避（A+B）· ≥1 次翻滚（C）· ≥1 次下盘（D）· ≥1 次腾跃（E，可放宽为全片 ≤2 且至少 1）。

- 闪避不是终点：闪完那一刻他已经在新角度出手——闪完就停 = 慢。
- 腾跃全片 ≤ 2 次、起跳与落地分两镜（冲刺段除外）；闪避不占额外拍。
- 数法见 `action-timing.md` 七。

## 铁律 11 · 每一击都挥满整条弧线，有起势、有分量

一个攻击动作走完三段：起势（重心沉、肩先转、拉到极限位置）→ 挥满（走完整条弧线）→ 过身（收势直接连成下一击起势），缺一不可。

- 力度写在身体上，不写在副词上：`❌ 他狠狠地打出` → `✅ 他整条右臂从后肩抡到前肩，重心压进前脚，拳锋走完整条弧线`。
- 起势不占额外拍——它就是上一个重拍组的第 3 拍；不许新起「蓄力」拍（= 慢动作）。收势不许停。
- 镜头不放开，挥得再满也看不见（配套铁律 6）；重拍组占 3 拍，密度不降。
- 动漫工具跟配额走（**配额本体见 `heavy-impact-playbook.md` 四**，此处仅速查）：残影只给每镜最快的一组挥击（单镜 ≤ 2 道、全片 ≤ 3 镜），静帧只落铁律 2 合法节点。
- 冲线 ≠ 残影：高速冲刺的整个身体是 motion blur（`a single blurred streak`），与残影堆叠（ghost trails）分开声明。
- **发力链是物理校验不是节奏分解**：攻击动作从触发到完成约 1 秒内，镜头描述必须写成一气呵成的爆发，严禁「先…再…然后…」分步句式——那是教学拆解，模型会跟着放慢。动作蒙太奇只切视角、不切慢速度。物理拆解与五点自查见 `action-physics.md`。
- 数法见 `action-timing.md` 八。

## 铁律 12 · 电影机位，严禁游戏视角

镜头是摄影机——每一镜为这一镜的接点重新选方位、高度、距离。三条禁用（命中即退回）：

| 禁 | 长什么样 |
|---|---|
| 横版侧视对决机位 | 街霸那种正侧面平视、两人并排站同一水平线互相出招、镜头站住不动 |
| 第三人称跟随 | 相机吊在后脑勺/肩膀后随人跑动；焊死在角色背后当操作视角 |
| 玩家视角 | 俯视战术视角 · 等距斜 45° · 平台跳跃斜视角 · 相机绕圈展示两人 |

两条合法（别矫枉过正）：

- 过肩跟拍合法——一镜一机位的独立机位、硬切走开；焊死在后背 = 禁。
- 纯侧向（正 90° 侧面）全片 ≤ 1 成，且不许平视并排、不许站住不动。斜侧（3/4 侧前）不算纯侧向、不占配额。

正面要求：一镜一机位、逐镜重选；方位与高度随意（俯拍/仰拍/贴地/过肩/反打/越轴写明事由）；景别与机位逐镜不同（同时是铁律 9 的防融合防线）。

**⚠️ 相邻镜硬规则（2026-09-28 用户实测抓出，从 `camera-language.md` 附录 D 升格）**

**相邻两个镜头若主体相同，必须至少满足其中一条，否则 = 同机位同景别切 = 违和：**

| 条件 | 量化标准 |
| --- | --- |
| **景别跨档** | 至少跨 **两档**（如 MCU → ECU 合法；MCU → CU **不合法**，只跨一档） |
| **机位夹角** | 两个机位的水平夹角 **≥30°**（否则读作跳切） |
| **主体变更** | 本镜主体与上镜不同（切入对方 / 切到道具 / 切到环境） |

**最高频翻车形态**：`过肩看 B 正面` → `从 B 斜侧拍 B`。两个机位都在 B 的正面环上、夹角目测 <20°，景别只跨一档 → **观众读到的是"同机位重新对焦"**。

**自查（必做）**：交付前逐对相邻镜问一句——「这两镜主体是不是同一个？景别跨两档了吗？机位夹角 ≥30° 了吗？」三问有一项答不上来就返工。调度图上量两个机位的角度，别目测。

景别档位序列（跨两档按此表数）：`ELS 大远景 → LS 远景 → MLS 中远景 → MS 中景 → MCU 中近景 → CU 近景 → ECU 大特写`。

自查词表（命中即报错；否定句放行）：

```
中文：横版 侧视 正侧面平视 并排对峙 第三人称 背后跟随 背后视角 锁定轴 玩家视角
      战术视角 俯视战场 斜45° 等距 绕圈展示 平台视角
英文：side-scrolling  straight side view  side-on locked  versus screen  fighting-game
      third-person follow  behind-the-shoulder follow  locked to the back
      player camera  gameplay camera  top-down tactical  isometric  orbit around the fighters
```

易误报：`over-the-shoulder` 本身不违禁——跟拍合法、焊死才违规；单独 `side view` 不直接判违规，要连「并排平视 + 站住不动」一起看。本条必须写进 H3 稿的 CAMERA 段。

镜头逻辑五条（轴线 180° · 30° 规则 · 视线匹配 · 银幕方向 · 动作匹配）与两条不可破（开场建立空间 · 同侧不出轴线）是地基，写法与越轴台阶见 `camera-language.md` 零节；每次大位移后重建空间。

## 铁律 13 · 严禁漫画式效果线

线路类特效整条归零——不是降配额，是不许出现：

| 禁 | 长什么样 | 扫这些词 |
|---|---|---|
| 集中线 / 速度线 | 从画面四角往里收、扫满整屏的辐射线 | 集中线 · 速度线 · 效果线 · 辐射线 · 放射线 |
| 漫画动作线 | 贴在人物/笔画边缘的冲击线、擦布线、爆炸线 | 动作线 · 冲击线 · 擦布线 · 漫画线 |
| 英文侧 | — | `radial speed lines` · `speed lines` · `action lines` · `impact lines` · `motion lines` · `converging lines` |

为什么：贴在图上的图形不是画面里真实存在的东西——一出现就把 3DCG 物理质感拉回漫画分格。

速度感改用四条承担（都不贴图）：① motion blur（`a single blurred streak`）② 元素拖尾 ③ 残影堆叠（受配额：单镜 ≤ 2 道、全片 ≤ 3 镜）④ 镜头语言（横移跟拍 · 被甩开再追上 · 贴地低角 · 镜头受击后仰）。

自查：中英词表各扫一遍，命中即报错（否定句放行）。

## 铁律 14 · 表情克制 + 布料发丝物理 + 质感光影默认块（全题材通用）

不用用户提醒，每稿默认写到位；他点名别的才算当轮例外。

① 表情克制——面部肌肉从不非常用力

- 表情永远自然、收敛：不许夸张瞪眼、咧大嘴、扭曲五官。情绪写在身体上（重心、呼吸、肩线、手的预备），脸部只给微表情（`a slight narrowing of the eyes`）。
- **写法铁纪（血泪教训）：即使在否定句或 rather than 结构里，也绝不点名「咧嘴/大笑/wide grin/皱纹/crease/nasolabial folds」等具象词**——模型会拿它当先验执行。一律正面句：
  `natural, restrained facial expressions — the face stays relaxed and keeps its smooth resting tension; emotion reads through the eyes, breath and posture`
  `a small contained smile` / `the emotion is carried entirely by the eyes` / `her face stays smooth, taut and still`
- **面部特写镜头内必须就地重申这句正面约束**，不能只靠全局风格块。
- 脸部来源仍归铁律 7：本条管「生成时怎么演」，不管「长什么样」。

**①-补 · 肌肉发力禁令（3DCG 专属，2026-09-28 实测翻车）**

**允许（零肌肉动作，安全）**：视线方向 · 眨眼（一拍）· 瞳孔缩放 · 口型开合度 · 唇的轻微分合 · 呼吸起伏 · 头部角度。

**严禁（面部发力动词，哪怕动作很小）**：
`pressed down` · `bites down` · `clenched` · `strained` · `tightened` · `grinding` · `forced` · `knitted` · `furrowed` · `trembling`

> **铁则：动作小 ≠ 安全。** 3DCG 管线一旦收到「面部肌肉发力」信号，就必然渲出肌肉牵动与纹路（眉头挤出、牙关外露、下颌绷紧、嘴角牵扯）——这就是用户实测见到的「表情用力过猛」。**微小发力动作比夸张表情更容易漏过自检，因为它不算「夸张」。**

**3DCG 情绪四载体**（情绪波动一律迁到这四处，脸上不加力）：
1. **呼吸**：`one long slow breath in through the nose, the chest rising and falling once`
2. **肩线**：`the shoulders settle one notch lower`
3. **重心**：`the weight shifts back onto the heels`
4. **手的姿态**：`the fingers of the free hand curl slowly and stop`

**改法对照**：

| ❌ 发力写法（现稿踩过） | ✅ 无发力写法 |
| --- | --- |
| `brows pressed down over the eyes` | `the gaze drops and holds on B's collar, the brow line stays smooth` |
| `bites down on the lower lip` | `the lips part slightly and close again, the mouth stays soft` |
| `the trembling stops as a single swallow is forced down` | `the shoulders settle one notch lower as the breath is let out slowly` |
| 嘴唇发抖 | `one long slow breath in through the nose, the chest rising and falling once` |

自查：表情词表扫 `grinning` / `grimacing` / `exaggerated expression` / `screaming face` / `wide-eyed` / `contorted`——命中必须在收敛语境；`nasolabial` / `smile lines` / `wide grin` / `crease` 一个都不许出现（含否定句）；**`pressed down` / `bites down` / `clenched` / `strained` / `tightened` / `grinding` / `forced` / `knitted` / `furrowed` / `trembling` 同样一个都不许出现（含否定句）**。逐镜问一句：这一镜的风力档位是多少？答不上来就是漏写。

② 布料 / 发丝物理默认真实——强度跟随环境，不跟随镜头需要

- 每稿默认写进风格总纲：
  `realistic cloth and hair simulation driven by the actual environment — garments drape, fold and flutter according to real fabric weight and wind strength; hair moves as real hair, whipping hard in strong wind, settling when the air is still`
- 风大 = 飘得厉害；无风 = 只随动作带起。一样都不动 = 人像木偶 = 违规。
- 逐镜只写「变了的那部分」：持续风效一次声明 + release clause（`storyboard-structure.md`），镜内只写方向或强度变化。
- 碰撞与次级运动要物理：布料甩到极点后回落、发丝遮脸后会被拨开，不是循环飘动的贴图。

③ 质感与光影默认块（以 `look-quality.md` 为准）

- **质感承诺是硬线**：用户说 3DCG = 全片 CG 角色 CG 渲染，任何镜头不许滑向真人实拍；用户没点名「真人」就永远不许出现真人。写实管线只管材质与光，不管脸的风格。
- 每稿默认把 `look-quality.md` 的英文底块原样写进风格总纲；他当轮点名别的质感方向才算例外，只改被点名的句子。
- 底块 Environment 段是强风档写法——环境静止的片降级为 `settling when the air is still`，不许硬套永不松懈。
- 图号是占位，映射以用户表述为准；没说就问（「A、B、C 各是图几？」），不问不猜。细则见 `look-quality.md` 入稿适配规则。

自查（③ 质感专属）：① 风格总纲是否原样含 `look-quality.md` 英文底块（或仅改了用户当轮点名的句子）② 质感承诺与用户点名一致（3DCG = 全片 CG 角色 CG 渲染，零真人镜头）③ 底块 Environment 段风力档位与场景实际一致（静止环境已降级处理）④ 图号映射已确认。表情词与风力档位的全局扫描见 ①-补 与 ② 的自查，不在此重复。
