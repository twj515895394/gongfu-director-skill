# 校验法手册

十套校验 + 蒙太奇衔接校验。规则全文在 `iron-rules.md` / `delivery-rules.md`（速查在 `SKILL.md`），本文件只讲怎么数、怎么判、怎么报。

- 结构类事实一律用脚本核，不靠肉眼。 脚本报「全盘皆错」时先怀疑脚本。
- 结论写在对话回复里，不落盘。校验脚本用完即删。

脚本写法五坑（踩过就要避开）

1. 切镜块别用 `md.split("## 镜 " + str(n))`——`## 镜 1` 是 `## 镜 10/11/12` 的前缀，会带上后面所有镜，拍数虚报。用 `re.split(r"\n## 镜 (\d+) · ([\d.]+)–([\d.]+)s", md)` 一次切好。
2. 同一时间戳可能有两处——镜首 `At 03.375s, CUT TO:` 与镜内那一拍同值。只取第一处会拿到半句误报。同时间戳的所有段都取出来，任一段命中即算通过。
3. 正则里的 `[^;.]*?` 会被 `<Subject 2>'s` 的句点截断——凡要跨过 `<Subject N>'s` 的匹配别排除 `.`，改用「取到下一个时间戳为止」的段切分。
4. `re.finditer` 的组号要数一遍——`m.group(2)` 而正则只有一个捕获组 = `IndexError` 崩在开头。
5. 日志用 Python 自己开 UTF-8 文件，别靠 shell 重定向——PowerShell 的 `*>` 产出 UTF-16 乱码；`print` 带 `flush=True`，否则异常一出缓冲区全丢。

## 一、时长校验

把镜内每个动作按物理最短耗时累加，与镜长比对：

```
镜长 − Σ(各动作最短耗时) = 余量
```

并行 = 零成本（不占独立时长）：持续环境元素（风 / 雨 / 雾 / 背景人流）·「保持手势」「定格」「维持姿态」· 已开始的持续状态 · 动作自然带出的次级效果（甩手 → 粒子飞出）。只有需独立起止的离散动作才占时间（抬手、合掌、转身、迈步、响指、出拳）。

| 余量 | 判定 | 处理 |
|---|---|---|
| ≥ 0.5s | ✅ 宽裕 | 保留原时长 |
| 0 ~ 0.5s | ⚠️ 偏紧 | 保留，标注需并行的动作 |
| = 0s | ⚠️ 临界 | 必须并行 |
| < 0s | ❌ 装不下 | 延长镜长，或调整 / 拆镜 |

常见动作最短耗时

| 动作 | 最短 | 备注 |
|---|---|---|
| 建立空镜 / 看清环境 | 0.5s | 不能省 |
| 手臂入画（从画外） | 0.4s | |
| 抬手到某高度 | 0.6~0.8s | 强调 slow 取上限 |
| 双手合掌 / 抓住 | 0.3s | |
| 突然甩开 / 松手 | 0.4s | |
| 表情建立 | 0.6~0.8s | |
| 镜头快退（snap pull-back） | 0.8~1.5s | 看幅度 |
| 减速到静止 | 0.5s | |
| 离地 + 悬浮上升 | 1.2s | 最不能压 |
| 高速破空冲出 | 0.6s | |

超载重灾区：多个连续招式、每招都要给出速度感的武打镜。

报数格式

```
Shot 1  3.0s  动作需 2.7s  余 +0.3s  ✅ 刚好够（③④ 需重叠）
Shot 2  8.0s  动作需 8.0s  余  0s    ⚠️ 临界，必须并行
```

同时给结论：哪几镜要调时长、调多少；哪几镜零余量但不可动（含用户写死的硬指标）；哪几镜余量最大、可承载额外创意。

装不下时：① 说清哪个动作装不下、差多少 ② 给两三个选项（延长镜长 / 合并动作 / 拆镜）③ 由用户决定，不自行删减他的设计。

## 二、密度校验（≥ 每秒 8 拍）

「一个回合」= 甲攻 → 乙应对 = 2 拍。 每秒 4 回合 = 8 拍/秒，每拍 0.125s。

- 总拍数 = 片长 × 8（10.125 秒 → 81 拍；1.250 秒的镜 = 10 拍 = 5 个回合）
- 拍点必须落在 0.125s 整格：`0.000 / 0.125 / 0.250…`，间隔全程恒为 0.125s，跨切点不断；每镜首拍 = 该镜起始时刻
- 必须按整秒跑滑动窗口，不能只用总平均：

```
窗口 [00,01) 8 拍 OK   [01,02) 8 拍 OK   …   [09,10) 8 拍 OK
窗口 [10,10.125] 1 拍（片尾余量）
>>> 不达标的秒：无
```

报数格式

```
第1镜 1.250s  10 拍  8.00 拍/秒  0.000..1.125  ✅
第2镜 1.250s  10 拍  8.00 拍/秒  1.250..2.375  ✅
第3镜 1.250s   9 拍  7.20 拍/秒                 ❌ 不合格，须重排
合计  81 拍   8.000 拍/秒   逐秒窗口最低 8 拍   ✅
```

与时长校验是两个方向，都要跑：时长问「够不够做完」，密度问「够不够多」。

## 三、移动与压制校验

| 判定 | 通过标准 |
|---|---|
| 没有站桩 | 任何一镜两人都原地不动、脚下没动作 = ❌。默认姿态是周旋：换角度 / 试探 / 微调距离（侧移、换步、绕向、探步），脚下始终在动 |
| 位移有授权 | 用户点名了被压制方 → 按他说的方向退；用户没说 → 位移只准「一点点」：一次半步、一镜 ≤ 1~2 步，不许自己造推进主线 |
| 有来回 | 每次退与每次拉开后面都有回推 / 再压近；只退不回、只拉开不压近 = ❌ |
| 拉开合法 | 激烈回合打完可拉开几步重置、喘口气再压回来——拉开后必有再压近 |
| 距离放开 | 周旋与拉开距离自由变化；仍禁「跑」「冲出去」「追」（要跑要追走用户点名的授权例外，见铁律 4） |

报数格式

```
压制关系来源：用户当轮未点名 → 全片只准「一点点」      ⚠️ 硬约束
第1镜  周旋（侧移换角度、重心在换）                    在动      ✅
第2镜  乙让出半步 → 立刻踩回原处                       来回闭合   ✅
第5镜  打完一套 → 拉开三步重置 → 甲压近                换气闭合   ✅
第7镜  甲被顶退半步 → 抢回                             回推       ✅
净位移：≤ 半步                                           ✅（未点名时）
```

用户没点名时的脚本核法：把正文所有位移句抽出（`退` / `让出` / `撤` / `走` / `进` / `移` / `拉开` + 量词），逐镜 ≤ 1~2 步；超了就是自己加了主线，必须删。「拉开」句单独标记，后面必须跟一个「压近 / 顶回」句才算闭合。

自查词：`站定` / `停住` 命中必须全落在否定句里。`原地`与`拉开`都不是禁词——原地镜合法但要跟上「人不停」；拉开是合法换气，后面必须跟上「再压近」。

镜头要跟着走（写法见铁律 4）——镜头钉死 → 人一动就出画 → 模型把人也钉死。

## 四、接触点数校验（空手）

空手一镜里可能同时有「架住的前臂 + 打出的拳 + 踩住的脚」三个接触点，点一多就糊成一团，模型会把两人揉在一起。

| 判据 | 合格 | 不合格 |
|---|---|---|
| 主接触点 | 每镜只设一个，其余用手持晃动与景深虚化带过去 | 一镜并列写三个接触点 = ❌ |
| 只许钝击 | 拳 / 肘 / 膝 / 胫 / 掌 / 前臂；掌压、拨腕、抓腕都算「接触」 | 写成凭空挨打——没接触却中招 |
| 接触要落人名 | 每次接触写清谁碰谁、碰在哪 | 只写「被打中」，不提谁出手 |

判据落在「拍」上，不落在「镜」上。 真正糊成团的是同一拍里并列两个接触点；同一镜可以有好几处接触，只要摊在相邻拍上、一拍一处就合法（实测认可稿：镜 1 有 2 个接触拍、镜 2 有 3 个）。改法是把多余的那个挪到下一拍，不是删掉——按「整镜只许一个」去砍，会把接触拍和特效数一起砍掉。

计数单位是「接触点」，不是「攻击线」。 两条攻击线撞在同一点（对撞）仍只有 1 个接触点，别数成 2 个。同理接触拍数 ≠ 引爆数：对撞那一种引爆点同时带两路元素，1 拍产出 2 次引爆。改完必须脚本重数这两个数（见 §九 陷阱 ③）。

报数格式

```
第1镜  接触拍 2（0.625s 前臂架腕 / 1.000s 拳砸前臂）      ✅ 摊在两拍上
第3镜  接触拍 1（2.750s 两记冲拳撞于同一点——对撞算 1 点）  ✅
第6镜  2.000s 一拍并列 2 个接触点                        ❌ 须把其中一个挪到 2.125s
```

旧稿改法：一镜写了「架住 + 同时出拳 + 同时踩脚」→ 保留主接触点，另两个挪到下一拍。

锁技 / 擒拿是特例：不是「一拍一处」的问题，是几何必须逐项可数——哪条腿压哪侧肩、膝盖夹哪个部位、手腕固定在哪。写成「夹住 / 锁住」这类抽象动词，生成必散架（`generation-feedback.md` 案例 1）。

## 五、切点位置校验

三个病灶都要数：

| 病灶 | 怎么数 | 目标 |
|---|---|---|
| 末拍落定：末拍写成「撞上 / 接住 / 锁死 / 钉住 / 站回 / 稳住」 | 逐镜取末拍文字，扫终态词表 | 0（终态末拍 = 拖沓根因） |
| 镜间顿：每镜以收势句结束，先停稳再被切 | 数 `The shot ends with` / `镜头结束时` | 0 |
| 镜内粘滞：每拍写成句号收尾的闭环句 | 镜内 句号 ÷ 分号 | 每镜 ≤ 1.0 |
| 「但」字自我拆台：先承认上一动作已完成 | 数「但」 | 不必计数，改用否定句 |

末拍终态词表（命中即不合格）

```
中文：撞上 撞在 砸在 接住 接上 卡住 锁死 钉住 站回 站稳 稳住 停住 顶住 压死 攥住 抓住 抓住不放 落回 落到
      滑到末梢 踩死 没站回 还没稳 一步没退 一寸没让
英文：slam  jam  lock  catch  catch it  planted  touching
      weight behind them  not an inch  comes to rest  settles
```

末拍进行态词表（必须命中至少一个）

```
中文：还在 还没 才 刚 已经 半路 起势 弧尾 往前 往上 转进
英文：still swinging  still travelling  still turning  already  as he  in the middle of
      on the way  coming down  rising into  not yet  leaves the line
```

撞击落点：把全片每一次「接触」的时刻列出，逐个核是否落在该镜末拍——落在末拍的一个都不许有。（撞击堆在镜尾 = 每镜以僵住的姿势收场，模型就演成停顿。）

句号数法：时间码 `1.300s` 里的点是小数点，要剔除。正则 `\.(?=\s+[A-Z<*])` 才算句末句号。

报数格式

```
第1镜  末拍判定=进行态 ✅  末拍=「拳还在往上走、人还在转」
第1镜  句号 1 / 分号 3 = 0.33  ✅     收势句残留：0  ✅
第2镜  句号 2 / 分号 5 = 0.40  ✅     交接字段：进行态 9/9  ✅
撞击落点：1.125 / 2.375 / 3.625 / 6.125 / 7.375 / 8.625 / 9.500 → 落在末拍者 0  ✅
```

静镜例外（见铁律 1）：只静镜头、人一直在动，动作已起步、还没落地时切走。

## 六、伤情表校验

打斗类交付前必须列伤情表并在回复里报出。

报数格式

```
第2镜  2.700s  甲  左侧眉骨   被肘打开，见血
第3镜  3.950s  甲  右手背     指节擦破，血糊手背
第4镜  5.650s  乙  右肋       被膝顶中，闷痛弯腰
第4镜  5.850s  乙  左颧       被重拳砸中，全片最重
甲：2 处    乙：2 处    差 = 0  ✅（差 ≤1 为合格）
倒地：无（两个人站到最后一格）
```

用户多数要「不要见血」（重击流默认口径）：全部命中被架住 / 卸掉，伤情表按 0 报，打击感改靠命中反馈与镜头微震（见 `heavy-impact-playbook.md` 三）。

| 判定 | 合格条件 | 不合格 |
|---|---|---|
| 数量平衡 | 两人伤口数相差 ≤ 1 | 5 : 2 = 单方面挨打，必须重写 |
| 双向还击 | 甲每挨一下，乙在同一镜或下一镜里还回来 | 前 7 秒某人一直挨打 |
| 倒地归属 | 由用户定，不自己安排 KO / 昏迷 | 擅自写「单膝跪地起不来」 |

写法见铁律 8：血走位置 · 血不会消失 · 收尾交代总账 · 复用已有的口子 · 出血克制。

## 七、动作分布校验（防「只会架挡」）

### 第一步：逐镜给守方化解归类

一镜里守方化解了几次，就记几次；一次化解只归一个大类（取主导）。归类靠动词，照下表 grep：

| 大类 | 命中词（中 / 英） |
|---|---|
| A 头身闪避 | 侧身闪 / 偏头 / 下潜 / 低头躲 / 后仰 / 铁板桥 / 侧倾 / 缩身 · `off the line` / `ducks under` / `arches back` / `leans clear` |
| B 位移闪避 | 侧滑步 / 出线 / 撤步 / 换步 / 绕步 / 周步 · `slides off the line` / `voids` / `passing step` / `traverses` |
| C 地趟翻滚 | 前滚翻 / 侧滚 / 后滚翻 / 抢背 / 地趟 / 鲤鱼打挺 · `rolls forward` / `rolls sideways` / `shoulder roll` / `kips up` |
| D 下盘腿法 | 扫堂腿 / 勾踢 / 绊腿 / 低鞭腿 / 膝撞 / 踩脚 · `sweeps a leg` / `hooks the ankle` / `trips` / `stomps down` |
| E 空中腾跃 | 后空翻 / 侧空翻 / 跃起 / 蹬竹 / 腾空转身 · `backflip` / `side-flips` / `leaps over` / `kicks off the bamboo` |
| F 上肢手段 | 拨腕 / 抓小臂 / 掌压前臂 / 肘击 / 肩靠 / 推肩 · `slaps his wrist` / `seizes the forearm` / `presses the forearm` / `elbow` / `shoulders him` |
| G 架挡（分母对照项） | 挡开 / 架住 / 格开 / 拨开 / 磕开 · `turns aside` / `beats down` / `takes it on the edge` / `rides it down` |

注意：A–F 全部算「不靠架挡」；只有 G 计入格挡分子。

### 第二步：三条判定

| 指标 | 合格 | 不合格 |
|---|---|---|
| 连用同类 | 相邻两镜大类不同 | 同大类连续 = ❌ 必须换类 |
| 格挡占比 | G ÷（A+B+C+D+E+F+G）≤ 0.33 | > 0.33 = ❌ |
| 八镜配额 | 每连续 8 镜：A~F 合计 ≥2 次纯闪避 · ≥1 次 C · ≥1 次 D · ≥1 次 E（E 可放宽「全片 ≤2 且至少 1」） | 缺项 = ❌ |

### 报数格式

```
第1镜  G 架挡              第5镜  B 侧滑出线
第2镜  A 下潜              第6镜  C 抢背翻滚
第3镜  G 架挡              第7镜  D 扫堂腿
第4镜  F 掌压前臂          第8镜  E 后空翻
──────────────────────────────────────────────
连用同类：0                        ✅
格挡 G=2 / 总化解 8 = 0.250        ✅（≤0.33）
八镜配额：A~F 6 次（纯闪避 A+B=2）· C 1 · D 1 · E 1   ✅
腾跃次数：全片 1 次                ✅（≤2）
```

脚本核时：A~G 命中表用整份关键词表逐类 count，再按镜号分段——一镜正文出现两个同类词算 1 次化解。报「配额不达标」先怀疑归类表漏词。

### 切片六坑（每条都真实栽过）

按回合切片对动作分类时，先把切片切干净，否则整表错位：

1. 别对已切好的片段二次 `split("[Shot ")`。 镜身正文会引用前一镜（`opening on the contact where [Shot 1] left it`），一 split 把本镜切断，分号数、句号比全报废。用外层切好的片段。
2. 先丢掉带时间码的标题行。 标题「（0.000–1.250 秒 · 10 拍）」里的 `1.250 秒` 也匹配 `X.XXX 秒`，会被当成首拍 → 回合错位一格。切片前先 `split("\n\n", 1)[1]`。
3. 片尾时刻不是拍。 时长清单里的 `8.750-10.125s` 会让拍点多 1——拍点只取 `0.000`–`10.000`。
4. 末镜会吞掉声场段：最后一句切片用 `split("overall_soundscape:")[0]` 封口，否则末镜句号比、词数被声场段污染。
5. 「约」字误报：检 `[约大約]\s*\d` 而不是单字 `约`——「硬约束」里也有「约」。
6. 中英词表不能混用：拿中文词表数英文稿全返回 0，看着像合格其实词表没对上。两套分开写、分开跑。

## 八、重拍组与幅度校验（防「原地抖手腕」）

24 帧 / 秒 → 一拍只有 3 帧。「一拍一个小动作」= 满屏手腕抖。本节核攻击有没有挥开（空手＝拳 / 腿走完整条弧线，持械＝剑）。

| 判据 | 怎么数 | 目标 |
|---|---|---|
| 重拍组数 | 重镜每镜 2 个、快镜每镜 1 个 | 全片挥开次数 = 组数（如 8 镜 → 12 次） |
| 跨拍数 | 每个重拍组占的拍数（起势 → 挥满 → 过身） | = 3 拍（9 帧） |
| 三段齐全 | 组内都有起势语、挥满语、过身语 | 逐组齐全 |
| 幅度词比 | 「小 / 贴 / 原地」类词 与「大 / 开 / 展开」类词 | 小 : 大 ≤ 2 : 1 |
| 起势不占额外拍 | 数独立的「蓄力 / 起势」拍 | 0——起势只能是上一个重拍组的第 3 拍 |
| 景别配套 | 重拍组所在镜的景别 | 中景（否则弧线被画框切掉） |

幅度词表

```
小：半步 一掌宽 一掌 贴着 贴身 零距离 原地 半个身位 只让开 一步没挪 一步没退
    一动不动 同一块地 踩回 顶不动
大：大步 弓步 跨 全力 全身 展开 伸直 拉长 大开 大合 转身一周 横扫 大弧 甩 抡
    跨步 探身 纵 跃起 腾空 滚出去 从肩到肩 从头到腰 弧尾
```

报数格式

```
重拍组：第1镜 2 · 第2镜 1 · 第3镜 2 · 第4镜 1 · 第5镜 2 · 第6镜 1 · 第7镜 2 · 第8镜 1
        合计 12 次完全挥开                              ✅
跨拍数：12 组全部 3 拍（9 帧）                           ✅
三段齐全：12/12（起势 / 挥满 / 过身）                    ✅
幅度词比：小 61 : 大 34 = 1.8 : 1                        ✅（≤2:1）
独立起势拍：0                                            ✅
末拍撞击：0                                              ✅
```

## 九、版本差异比对（重设计必做，防「换皮不换骨」）

前提有一份上一版分镜。顺序：重设计动笔前不许打开它（硬规则 13），写完再做本节。

逐拍对齐：两版按「镜号 + 拍序」切拍，两种比法都跑——① 字符串相等（抓一字不差）② 逐拍最相似度（`difflib`，抓换名词 / 换语序）。镜数不同不按位对齐，直接算「新版每拍对旧版全部拍取最高相似度」。

```python
import re, difflib
def beats(p):
    t = open(p, encoding='utf-8').read(); out = []
    for m in re.finditer(r'(?m)^## 镜 (\d+) .*$', t):
        seg = t[m.end():].split('## 镜 ')[0].split('\n---')[0]
        out += [re.sub(r'^\d+\) [\d.]+s ', '', l).strip()
                for l in seg.split('\n') if re.match(r'^\d+\) ', l)]
    return out

hi = sum(1 for b in beats(new) if max(difflib.SequenceMatcher(None, b, o).ratio()
                                    for o in beats(old)) > 0.75)
```

| 判据 | 怎么数 | 目标 |
|---|---|---|
| 逐拍一字不差率 | 同位置两拍字符串完全相等数 ÷ 总拍位 | ≤ 20% |
| 逐拍最相似率 | 新版每拍对旧版全部拍取最高 `difflib` 比值，> 0.75 记一次 | ≤ 20% |
| 同动作率 | 脚本比不出的人工过：只换名词的拍也算复用（落叶→碎屑 / 竹竿→墙 / 风→尘） | 逐条报出，计入总量 |
| 六轴差异 | 切点节奏 · 招式族 · 攻守形态 · 静帧位置 · 特效落点 · 镜头基调 | 逐轴都有差异 |

报数格式

```
逐拍一字不差：81 拍位中 36 拍相同 = 44%                 ❌ 不合格（>20%）
逐拍最相似：81 拍中 近乎相同(>0.75) 3 拍 = 4%            ✓
同动作（只换名词）：镜1「砸空入落叶」→「砸空入地面碎屑」等 6 处   ❌
六轴：切点节奏 有 · 招式族 有 · 攻守形态 有 · 静帧位置 有
      · 特效落点 有 · 镜头基调 有                        ✓ 换骨
```

六轴全同、只有「特效 / 镜头 / 环境」变了 = 换皮，一律退回重做，不许交付。

四条实测陷阱：
① 招牌数字（重拍组数 / 挥开次数）必须脚本重数——人工数会把 19 组写成 21 组；
② 特效措辞全篇逐字统一——对撞处图省事写 `the fire and the lightning` 而别处写 `embers / plasma`，模型会把前者渲染成更大的火；
③ 拆拍 / 合拍会改掉「接触拍数」——「同一拍两处接触」拆到相邻两拍后接触拍数会变，引爆数不变；凡「拍数」类数字（接触拍 · 挥开拍 · 静帧拍），改完一律脚本重数，别沿用上一版的数；
④ 「同一骨架的放大版」不是重设计，本节判据不适用。 用户看完说「特效太少 / 面积再大点」= 要同一骨架只放大某一轴。此时必须先问清放开哪几条禁区再动笔；产出后本节照跑，但交付说明里明示「本版与上一版六轴中五轴相同、只有 X 轴变化，重合是用户指定、非换皮」——不许把 44% 最相似率悄悄咽下去，也不许为过判据擅自改动作。判据照报，但只在「跨骨架」的比较上做合格判定。

## 十、母题自洽 + 节奏段次序校验

① 母题里的绝对句，必须逐拍落成可扫词表。 分镜开头母题段常写绝对句——「没有一次是躲开的」「几乎不架挡」「谁都没被按住」。这三句是对逐拍的承诺，写完用脚本全片扫：

| 母题声称 | 扫什么 | 命中要求 |
|---|---|---|
| 没有一次是躲开的 | `躲` `让开` `让身` `闪开` `偏开` `侧身避` | 全部落在否定句里（`躲` 只许出现在「没有一次是躲开的」本身） |
| 几乎不架挡 | `架` `挡` `格` | 只许出现在「没在挡」「格挡只有 X 次」这类句子里 |
| 谁都没被按住 | `按住` `压住` `锁住` `扣住` | 每次都必须写明「同一拍就松开」 |

声明与逐拍打架时，改逐拍、不改声明（声明是用户选的骨架）。改法：闪避改写成失误或被化——「乙的头往弧尾里低」→「线自己偏了半寸」；「乙的下颌偏出线外」→「被这一掌把线按偏出去」。母题才立得住。

② 切点节奏段的长短镜次序，必须与逐镜时长逐条对齐。 只核总和会漏：集合对、总和也对、只是次序错，肉眼扫不出。做法：脚本打印逐镜时长序列，与节奏段数字逐个数位比。

③ 母题段必须整体搬进新版——不能只搬动作、漏了绝对句。 「同骨架放大版」正文逐拍照抄、只改特效层，极易把开头母题声明整段丢掉。验收动作：`躲` 在新版里必须出现且只出现 1 次（就是那句否定句本身）；`让开 / 让身 / 闪开 / 偏开 / 侧身避` 一次都不许出现。

④ 骨架照抄时，`[标记]` 与旧数字要一起换。 同骨架版换了元素层，旧标记必须换成新标记，且新旧标记不许同时存在（脚本扫旧标记命中数应为 0）。旧版禁用句（`绝不拖尾` / `绝不满屏`）也一并删净，否则与新开放项直接打架。

# 蒙太奇衔接校验（快剪必做）

唯一标准：上一镜的结束状态，必须严丝合缝等于下一镜的起始状态。 不是「大体连贯」，是等号。中间任何需要观众脑补的空白，就是断点。

九种匹配类型（每次转场必须指定其一）

| 类型 | 含义 | 例 |
|---|---|---|
| 视线匹配 | A 望向 B → 切到 B 的视角 / B 的脸 | 对峙 → 反向过肩 |
| 动作焦点匹配 | 双人远景 → 切到即将接触的精确部位 | 对峙 → 出拳的手特写 |
| 镜像动作匹配 | A 做某动作 → B 做结构对称的同一动作 | A 抬拳 → B 踏步 |
| 动作延伸匹配 | 同一段位移的延续与加速 | 半步 → 全程冲刺 |
| 动作分解匹配 | 全景一击 → 对同一次接触做紧角分解 | 中景接触 → 紧特写相压 |
| 动作延续匹配 | 上一镜末端动作 → 下一镜以其为主景 | 收拳 → 收拳为主景 |
| 动作结果匹配 | 动作 → 它落到地面的必然结果 | 下砸 → 被架住 |
| 动作链匹配 | 同一段接触的收束 | 架住 → 松手后撤 |
| 循环闭合匹配 | 收尾姿态 = 开场姿态 | 后撤 → 回到初始距离 |

产出格式：逐接点列出，并报接点总数与闭合数：

```
1→2   A 望向 B / B 望向 A（视线闭环）      OK
2→3   对峙 → 切到 B 的手                    OK
```

发现断点要指出是哪个接点、差在哪个动作状态上，并给修改选项。

三个容易漏的暗礁

- 音效段幽灵引用：「第几次撞击」数错，或引用不存在的镜号——出稿前把次数与镜号逐个对回正文。
- 禁词自证循环：回复里写「全文无某某词」，这句话本身含该词。改说「正文描写内不含」。
- 同一接点的匹配类型别重复计数：转场处写一次、校验再列一次，统计「类型覆盖」会翻倍。
