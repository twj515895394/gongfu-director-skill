用户要的：「你可以给我一个动作线模板，我以后填着写。」

他填这张表发过来，本 skill 直接出稿。空白模板在项目工作目录 `动作线模板.md`（那是他填的那份）；
本文件是模板的规范说明——解释每一栏为什么存在、收到后怎么解析、哪些栏空着该怎么补。

## 一、模板全文（空白版）

````text
## 1 · 参考图
- 图 1 = ______（角色 ___ 的四视图：面部特写 / 正面全身 / 正左侧面全身 / 背面全身）
- 图 2 = ______（角色 ___ 的四视图）
- 图 3 = ______（场景：___）

## 2 · 环境与方位
- 场景：___
- 一直在动的东西：___（风 / 落叶 / 云海 / 雨 / 头发衣料）
- 方位（全片不变）：画面左 = ___，画面右 = ___

## 3 · 动作线（一行一步，严格按时间顺序）
| # | 谁 | 做什么 | 对方怎么反应 | 结果（位移 / 状态） | 我要的镜头 |
|---|---|---|---|---|---|

## 4 · 结局
- 谁倒下 / 谁赢：___
- 见血：要 / 不要
- 最后一个镜头：___

## 5 · 硬要求
- 慢动作：不要 / 要（在 ___：命中前蓄力 / 命中那一瞬 / 差点被打中）
- 音乐：不要 / 要（___）
- 时长：___ 秒（不填我定）

## 6 · 风格词（照抄或改）
````

## 二、每一栏为什么存在

| 栏 | 对应规则 | 空着会怎样 |
|---|---|---|
| 参考图 | 铁律 7（脸只取最左、零外貌描述） | 没图就走纯文字生成，必须问他要 |
| 方位（全片不变） | 铁律 12 附（轴线 / 银幕方向） | 这是防观众看晕最有效的一栏——他填一次，我锁死全片并写进约束块与 retention |
| 对方怎么反应 | 铁律 5（反应先于命中） | 必填。不填就没法保证「起躲早于命中」，打斗会变回合制 |
| 结果（位移 / 状态） | 铁律 4（周旋 / 压制 / 拉开）+ 大位移交代 | 大位移我补交代镜（落点、离多远），否则观众丢失位置 |
| 我要的镜头 | 硬规则 14 | 他写了就照办、不受配额约束；留空则我按 `camera-language.md` 设计 |
| 慢动作 | 铁律 2 | 不填 = 全片 0 次。填了必须落在合法节点，并显式写变速曲线 |
| 音乐 | 硬规则 7 | 不填 = 无音乐，`non_diegetic_music: N/A`（必须显式写 N/A，不能留空） |
| 时长 | h3 的 duration 网格 | 不填我定；定完按真实网格算真实秒数（如 `duration 10` = 10.125s） |

## 三、收到后怎么解析

1. 动作线的行数 ≈ 内容量——按它估算时长与镜数。铁律 3 要求镜数 ≥ 片长秒数，
   先定时长再定镜数，不够就把长步拆成两镜，不要硬塞回合进一镜。
2. 「我要的镜头」列出来的必须全部落位，且落位后要回查顺序——他写的动作线顺序就是最终顺序，
   不要自作主张调整。他写哪一步在前，就是哪一步在前；有疑问先问，不要自行优化。
3. 「对方怎么反应」逐条落成稿子里的反应句，并核「起躲早于命中」。
4. 方位填了就锁死，写进结构约束块 + `retention_analysis` 的场景行，两处都要。
5. 风格词照抄，不要翻译、不要改写、不要按口味删减。

## 四、两个容易踩的坑

- 他漏填「方位」时不要自己编一个写死——回头问他，或者只在稿里写「两人相对位置保持稳定」
  这类不锁死的表述。编一个方位再锁死，一旦与他脑内画面相反，整片空间全错。
- 动作线只有攻没有守时（整列「对方怎么反应」空着），先问他是不是打算写成单方面压制；
  单方面挨打违反铁律 8（伤情 / 谁倒下由他定），也可能是他懒得填。不要默认补一套反应。
