# 参考片段研究协议

用户定案：给出模棱两可的提示词时，要搜罗全网类似的现代片段学习；2008 年以前的过时影片不用学——更偏向现代电影的分镜、打斗、特效。

定位：导演助理从「照创意写」升级为「先研究再写」。用户给的常常是一句话、一个感觉、一部片的味道——这种情况不许直接动笔。

## 一、何时搜（创意模糊时必搜，清晰时可不搜）

判据：能不能从创意里直接读出「镜头语言」。读得出 → 不搜；读不出 → 必搜。

| 情况 | 例 | 动手前 |
|---|---|---|
| 模糊 | 「做个打斗，要有气势」「像最终幻想那种感觉」「我不太确定，你看着办」 | 必搜：先找同类型的现代片段，看镜头是怎么组织的 |
| 半模糊 | 说清了人物、场景、动作，但没说镜头怎么走 | 搜（只搜镜头语言部分） |
| 清晰 | 给了镜数、时长、参考图映射、点名要长镜头或快剪 | 不搜，直接写 |
| 点名要搜 | 「你搜一下现在别人怎么拍的」 | 必搜，且要报搜索结果 |

不搜的时候不是不研究——而是读 skill 内部的参考源（`long-take-directing.md` 的参考源表 · `action-sourcebook.md` · `unarmed-combat-classics.md` · `elemental-barrage.md` · `vfx-quality.md`）。

再加一条：涉及经典动作套路时，即使创意清晰也先搜。
劈子弹、跳楼、贴墙滑行、立体机动、拔刀斩这类有成熟套路的动作，全网早就有人拍过、且拍法有公认的好坏。「创意清晰」只解决「他知道要什么」，不解决「这类动作的镜头语言我学过没有」。
判据：创意里只要含经典动作套路，先搜套路的镜头语言，再动笔。

## 二、年代线（2008 硬线 + 手工白名单）

- 2008 年以前的作品一律不学，不管多经典（理由：要吃现代电影的语言）。
- 白名单由用户点名，产出方不许自己加。他点了某部老片，才可把它当参考源。
- 灰区判定：一部 2008 年后的作品用了老派手法（如模仿 90 年代武指风格）——只学那部片自己的现代处理（机位 / 剪辑率 / 特效合成），不学它模仿的老派部分。
- 同系列跨年代：系列横跨 2008（如某系列 2006 起步、2015 续作）——只取 2008 后的那几部。

---

## 三、搜什么（检索式构造法）

优先做的一步：先查「这个点子有没有套路名」。

这是性价比最高的搜索动作。绝大多数画面点子都已经被命名、被系统整理过，一旦拿到套路名，片单、各种处理法、甚至"哪些做法用烂了"全是现成的。入口用 TV Tropes（`Wall Run` / `Wall Crawl` / `Gravity Shift` 这类条目名），中文侧可用「名场面 / 拉片 + 关键词」。

> 实测教训：做「两人在玻璃幕墙上滑行打斗 + 镜头转 90°」时，只搜了镜头的旋转语言（roll / pan / spin 的区别），没搜这个前提本身——于是把有正式套路名（`Wall Run`）、作品列表极长的一个老题目当成了原创从零设计，用户直接反问「全网没有这种的打戏吗，都没有参考的吗」。这属于漏搜，不是搜不到。以后先搜套路名，再搜镜头语言。

三轴相乘：`内容轴 × 剪辑轴 × 质感锚`。中文与英文各搜一轮（英文侧的术语更具体）。

| 轴 | 词 |
|---|---|
| 内容轴 | 打斗 / 空手格斗 / 法术对轰 / 追逐 / 群战 / 立体机动 |
| 剪辑轴 | 长镜头 / 一镜到底 / oner / long take / 快剪 / 蒙太奇 / 摄影机运动 |
| 质感锚 | 电影感 / CG 特效 / 粒子 / 实拍合成 / 动画运镜 / 现代动作片 |

英文侧高命中词：`long take fight scene` · `oners` · `oner action sequence` · `camera movement` · `tracking shot choreography` · `cinematography breakdown` · `staging action` · `invisible cuts` · `whip pan` · `Steadicam choreography` · `fight scene blocking`。

中文侧高命中词：`一镜到底 运镜 解析` · `长镜头 打斗 设计` · `拉片` · `镜位分析` · `摄影机运动 解析`。

要避开的结果类型：影评（谈主题不谈机位）· 票房新闻 · 演员访谈。只取「镜头怎么动的」那类内容（拉片、摄制解析、幕后、运镜分析）。

## 四、提取什么（只取三样，其余一律不取）

取
1. 机位——方位 / 高度 / 距离，以及为什么是这个位置。
2. 运动——摄影机怎么动（推、拉、摇、移、绕、甩、升降），以及动因（跟着谁、被什么带动）。
3. 节奏——什么时候加速、什么时候反向、切点或节拍落在哪一刻。

不取
- 情节与桥段——不抄"谁在什么情况下做了什么"。
- 具体招式序列——不抄别人的连招（那是复制，也是版权雷区）。
- 角色与设定——不引入搜到的角色、武器名、招式名、组织名。
- 作品名——分镜与 H3 稿里一个字都不许出现作品名、导演名、片名（模型会试图整体复刻那部片子）。作品名只允许出现在对话回复里，用来说明"我参考了哪一类做法"。

> 提炼标准：把搜到的东西压成一句抽象的镜头语言描述。
> 例：不写「学《进击的巨人》立体机动那一幕」→ 写「镜头贴角色侧后方随他冲向纵深标靶，在悬停瞬间切进过肩视点让他自上而下瞄准，再从被攻击方反打给他脸部特写」。

---

## 五、搜索是内化动作，不落盘

- 不写研究笔记文件、不存片单、不建参考库——研究结论直接进这一稿的分镜与提示词。
- 交付物只有硬规则 1 那几件（分镜表 + 调度图 + 按需的 H3 提示词），研究材料不混进交付目录。
- 对话回复里最多报一句：「创意偏模糊，参考了三类现代做法（跟随式长镜 / 三维穿梭 / 高密度快剪），已内化进镜头设计」。
- 不许把搜索过程、链接、片名清单堆进回复——用户要的是稿，不是书单。

---

## 六、反雷同在这儿的作用

研究的目的不是复刻，是校准镜头语言。

- 搜到的东西只用来回答一个问题：「这类场景，现在的片子通常怎么组织镜头？」
- 不许把搜到的任何一部的具体镜头序列照搬进稿——那等于用别人的片子当骨架，与硬规则 13（换骨不换皮）直接冲突。
- 搜完照样跑六轴差异清单：切点节奏 / 招式族 / 攻守形态 / 静帧位置 / 特效落点 / 镜头语言基调。研究让镜头语言更多样，不是更容易撞车。

---

## 七、四个坑

1. 拿影评当运镜资料——影评讲主题、讲意义，不讲机位。要拉片 / 摄制解析类内容。
2. 把作品名写进稿——模型会整体复刻那部片。作品名只留在对话回复里。
3. 搜完就抄桥段——桥段是别人的创意，我们要的只是机位的组织方式。
4. 只搜镜头语言、不搜前提——镜头语言再清楚，前提本身可能是老题目。顺序是：先搜"这有没有套路名" → 再搜镜头语言 → 才动笔。 漏掉第一步会做出重复劳动的东西，而且用户看得出来。
